VIDEO 1: The ε–N Definition and First Proofs
Target length: ~9 minutes
Sources: Zorn §2.1; Hirst §4.1

Core message: Convergence is a statement about a quantifier pattern.
The shape of the pattern — ∀ε ∃N ∀n ≥ N — is what every proof must
produce. The game is: given ε, find N.

------------------------------------------------------------------------

Opening: What Is a Sequence? (0:00–1:00)

Write on board:
  A sequence is a function  a : ℕ → ℝ.
  We write (a_n) or a_n for the nth term.

  Examples:    1/n,    n/(n+1),    (-1)^n,    (-1)^n / n.

Say: A sequence is just a list of real numbers indexed by the natural
numbers. Look at the four examples. Which of them have a limit, and
what would we want "has a limit" to mean precisely? That is what we
have to pin down today, because the intuitive answer — "the terms
get close to L" — is not yet a usable definition.

------------------------------------------------------------------------

The Definition, One Piece at a Time (1:00–4:00)

Write on board:
  a_n → L  means:
    for every ε > 0,
    there exists N ∈ ℕ such that
    n ≥ N  ⇒  |a_n - L| < ε.

Say: I want to write this on the board slowly because the order of
the quantifiers is the entire content. Let me unpack it clause by
clause.

Say: "For every ε > 0" — the tolerance ε is arbitrary. Think of it
as picked by an adversary. They get to make ε as small as they like.

Say: "There exists N ∈ ℕ" — the index N is what WE choose, AFTER we
have seen ε. So N is allowed to depend on ε. In fact it almost
always does.

Say: "For all n ≥ N, |a_n - L| < ε" — from index N onward, every
single term lies within ε of L.

Say: That order — ∀ε, then ∃N, then ∀n — is non-negotiable. If you
swap the first two quantifiers and write "there exists N such that
for every ε," you get a different (and usually trivial or false)
statement. Quantifier order is content, not bookkeeping.

Write on board:
  [Number line picture]
  ----|----[==========L==========]----|----
            L-ε                   L+ε

  All a_n for n ≥ N fall inside the shaded band.

Say: Geometrically: draw a number line, mark L, shade the interval
(L - ε, L + ε). Convergence says: no matter how narrow the shaded
band, from some point on, ALL the dots fall inside it.

------------------------------------------------------------------------

The Proof Template: a_n = 1/n → 0 (4:00–7:00)

Say: Now let me do a full ε–N proof live, so you see what one looks
like. The claim is 1/n → 0. I will keep scratch work and the formal
proof visibly separate, because both are required.

Write on board:
  SCRATCH WORK:

  Given ε > 0, want |1/n - 0| = 1/n < ε.
  That is, want  n > 1/ε.
  By the Archimedean Property, such n exists.
  So: choose N ∈ ℕ with N > 1/ε.

Say: The scratch work is where the choice of N comes from. We work
backward from what we want — |1/n| < ε — and figure out which N will
make it true. Notice the appeal to the Archimedean Property; that is
where ℝ's structure enters.

Write on board:
  FORMAL PROOF:

  Let ε > 0.  By the Archimedean Property, choose N ∈ ℕ with
  N > 1/ε.  Then for all n ≥ N,

      |a_n - 0|  =  1/n  ≤  1/N  <  ε.

  Therefore a_n → 0.  ∎

Say: The formal proof restates the result of the scratch work in a
clean, linear order, with no backward reasoning. It begins "Let
ε > 0" — a fresh ε supplied by the adversary — and ends with the
inequality |a_n - L| < ε for all n ≥ N. That is the shape every
ε–N proof must have.

Say: I want to stress: KEEP the scratch work and the formal proof
separate, and submit BOTH. The scratch work shows where the choice
came from. The formal proof verifies that the choice works. Graders
in MAT 5610 will expect both.

------------------------------------------------------------------------

Closing: Negation Preview (7:00–9:00)

Write on board:
  a_n ↛ L  means:
    there exists ε₀ > 0 such that
    for every N ∈ ℕ,
    there exists n ≥ N with
    |a_n - L| ≥ ε₀.

Say: Notice the quantifier flips. ∀ becomes ∃, ∃ becomes ∀, the
inequality reverses, and the strict < becomes ≥. Mechanical, but
worth doing once carefully.

Say: This negation is how you prove a sequence diverges by definition.
You will use exactly this pattern in the practice set to show (-1)^n
diverges: produce a fixed ε₀ that defeats every choice of N.

Say: We will dwell on negation more in the study guide. For now, just
notice that proving divergence is not "show it does not converge by
shrugging" — it is "produce the witness ε₀ that ruins every N."

VIDEO 2: Limit Laws, the Squeeze Theorem, and Monotone Convergence
Target length: ~9 minutes
Sources: Zorn §2.1 (Thm 2.3), §2.2

Core message: Once you have 1/n → 0, the Algebra of Limits lets you
read off many limits without returning to the definition. The
Monotone Convergence Theorem is the first place the Completeness
Axiom actively powers a proof.

------------------------------------------------------------------------

The Algebra of Limits (0:00–3:00)

Write on board:
  ALGEBRA OF LIMITS:
  If a_n → A and b_n → B, then
    (i)   a_n + b_n  →  A + B
    (ii)  a_n · b_n  →  AB
    (iii) a_n / b_n  →  A/B    (provided B ≠ 0 and b_n ≠ 0)
    (iv)  c · a_n    →  cA     (c constant)

Say: Once you have one or two convergent sequences in your pocket —
say 1/n → 0 and the constant sequence c → c — the Algebra of Limits
lets you build up many more limits without returning to the ε–N
definition every time.

Say: I am not going to prove these in full. The proofs are in
Zorn §2.2, and the study guide walks through the sum case carefully.
Let me just sketch why the sum law works, because it is the
prototype.

Write on board:
  Sketch (sum law):

  |(a_n + b_n) - (A + B)|
      = |(a_n - A) + (b_n - B)|
      ≤ |a_n - A| + |b_n - B|        (Triangle Inequality)

  Make each piece < ε/2:
    pick N₁ so n ≥ N₁ ⇒ |a_n - A| < ε/2,
    pick N₂ so n ≥ N₂ ⇒ |b_n - B| < ε/2,
    take N = max(N₁, N₂).

Say: That "split into pieces, bound each by ε/2, then add" pattern
is the engine of every Algebra-of-Limits proof. The Triangle
Inequality from Module 2 is what makes it work.

Write on board:
  Application:

         3n² + 2n - 1               3 + 2/n - 1/n²        3
   lim  ───────────────  =  lim  ───────────────────  =  ───
         4n² + 5                   4 + 5/n²               4

Say: Divide numerator and denominator by n². Then 2/n, 1/n², 5/n²
all tend to 0 by the Algebra of Limits applied to 1/n → 0. The
constants stay put. Apply the quotient law. The limit is 3/4.
This is exactly Worked Example 2 — read it for the careful
write-up.

------------------------------------------------------------------------

The Squeeze Theorem (3:00–5:00)

Write on board:
  SQUEEZE THEOREM:
  If  a_n ≤ b_n ≤ c_n  for all (large) n,
  and  a_n → L  and  c_n → L,
  then  b_n → L.

Say: Picture two sequences closing in on the same limit. A third
sequence trapped between them has nowhere to go but to the same
limit. That is the Squeeze.

Write on board:
  Quick example:    b_n = sin(n) / n.

  Since |sin(n)| ≤ 1 for all n,
        -1/n  ≤  sin(n)/n  ≤  1/n.

  Outer sequences:  -1/n → 0   and   1/n → 0.
  By Squeeze:        sin(n)/n → 0.

Say: This is a sequence we cannot easily attack with ε–N directly,
because sin(n) bounces around. But we do not need to — we squeeze
it between two simple sequences whose limits we already know. This
example reappears in the practice set.

------------------------------------------------------------------------

Bounded + Monotone = Convergent (5:00–8:00)

Write on board:
  MONOTONE CONVERGENCE THEOREM:
  Every bounded monotone sequence in ℝ converges.

  (Increasing version:)
  If (a_n) is increasing and bounded above, then
        a_n → sup{a_n : n ∈ ℕ}.

Say: Now I want to sketch the proof, because where completeness
enters is the whole point.

Write on board:
  Proof sketch (increasing, bounded above):

  (1) S = {a_n : n ∈ ℕ} is nonempty and bounded above.
      ⇒  By the COMPLETENESS AXIOM, sup S exists in ℝ.
      Let L = sup S.

  (2) Given ε > 0, by the ε-characterization of sup,
      there exists N with  a_N > L - ε.

  (3) Since (a_n) is increasing and L = sup,
      for n ≥ N:    L - ε  <  a_N  ≤  a_n  ≤  L.

  ⇒  |a_n - L| < ε for n ≥ N.   ∎

Say: [Circle the appeal to completeness in step (1).]
This is the FIRST theorem in the course that cannot be proved
without the Completeness Axiom. In ℚ, this theorem is FALSE — the
rational truncations of √2 are increasing and bounded above by 2,
but there is no rational supremum. The MCT is where we cash in
the structure of ℝ that we set up in Module 2.

------------------------------------------------------------------------

Closing: Forward Pointer (8:00–9:00)

Say: Worked Example 3 applies the MCT to a recursive sequence:
a₁ = 1, and a_{n+1} = √(2 + a_n). The limit cannot be found by
direct ε–N manipulation because we do not have a closed form for
a_n. Instead, we show the sequence is increasing, show it is
bounded above by 2, conclude convergence by MCT, and only then
solve for the limit by passing to the limit in the recursion.
That four-step template — increasing, bounded, converge, solve —
is one you will use repeatedly. Read Worked Example 3 carefully.

VIDEO 3: Subsequences, Bolzano–Weierstrass, and Cauchy Sequences
Target length: ~10 minutes
Sources: Zorn §2.3–2.4

Core message: Two structural theorems about sequences in ℝ that
both rest on completeness. Bolzano–Weierstrass says bounded
sequences always have convergent subsequences. Cauchy completeness
says: in ℝ, "getting close to itself" is equivalent to convergence.

------------------------------------------------------------------------

Subsequences (0:00–2:00)

Write on board:
  A subsequence of (a_n) is  (a_{n_k})  where
        n_1 < n_2 < n_3 < ⋯
  is a strictly increasing sequence of indices in ℕ.

Say: A subsequence is what you get by picking out an infinite
ordered subset of the indices. The order has to be preserved, and
you have to take infinitely many terms.

Write on board:
  Example:    a_n = (-1)^n.

  Even subsequence:    a_{2k} =  1   →   1.
  Odd  subsequence:    a_{2k+1} = -1   →  -1.

  Two different subsequential limits  ⇒  (a_n) diverges.

Say: Here is the inheritance principle: if a_n → L, then EVERY
subsequence also tends to L. Contrapositive — and this is the
useful direction — if you can exhibit two subsequences with two
different limits, the original sequence diverges. That is the
cleanest way to prove (-1)^n diverges, and it is exercise S4 in
the practice set.

------------------------------------------------------------------------

The Bolzano–Weierstrass Theorem (2:00–5:00)

Write on board:
  BOLZANO–WEIERSTRASS:
  Every bounded sequence in ℝ has a convergent subsequence.

Say: Let me emphasize what this is saying. It does NOT say bounded
sequences converge — they do not, look at (-1)^n. It says you can
always EXTRACT a convergent piece. There is some convergent
sub-sequence hiding inside.

Say: I am not going to prove BW in full. Instead let me sketch the
two standard strategies, and direct you to Zorn and Bauldry for the
careful proofs.

Write on board:
  Strategy 1 — monotone subsequence:

  Fact: Every sequence in ℝ has a monotone subsequence.
  If (a_n) is bounded, so is the monotone subsequence.
  Apply MCT  ⇒  it converges.

  Strategy 2 — bisection:

  Halve the bounding interval [a, b].
  At least one half contains infinitely many terms; pick that one.
  Halve again. Continue.
  Interval lengths → 0; pick one term from each level.
  The chosen subsequence converges (Cauchy / nested-intervals).

Say: Both strategies rest on completeness — either directly via
the MCT, or via a nested-intervals argument that is itself a
consequence of completeness. There is no way to prove BW without
the Completeness Axiom. In ℚ, BW is false.

------------------------------------------------------------------------

Cauchy Sequences (5:00–8:00)

Write on board:
  (a_n) is CAUCHY if
    for every ε > 0,
    there exists N ∈ ℕ such that
    m, n ≥ N  ⇒  |a_m - a_n| < ε.

  (No mention of a limit.)

Say: I want to underline that last line. The Cauchy condition is
about terms of the sequence getting close to EACH OTHER, not close
to some external limit L. You can check whether a sequence is
Cauchy without ever guessing what the limit might be. That is
exactly why this condition is so useful: it lets you certify
convergence in ℝ without producing the limit first.

Write on board:
  THEOREM (in ℝ):
  (a_n) converges  ⇔  (a_n) is Cauchy.

Say: Let me sketch both directions.

Write on board:
  (⇒)  Suppose a_n → L.
       Given ε > 0, pick N so n ≥ N ⇒ |a_n - L| < ε/2.
       Then for m, n ≥ N:
           |a_m - a_n| = |(a_m - L) + (L - a_n)|
                      ≤ |a_m - L| + |L - a_n|
                      < ε/2 + ε/2  =  ε.
       So (a_n) is Cauchy.

       [Does NOT need completeness.]

Say: That direction is the same Triangle Inequality split-and-bound
pattern we have been using all module. No completeness needed.

Write on board:
  (⇐)  Suppose (a_n) is Cauchy.
       Step 1: Cauchy ⇒ bounded.   (standard ε=1 argument)
       Step 2: By Bolzano–Weierstrass, (a_n) has a
               convergent subsequence  a_{n_k} → L.
       Step 3: Triangle inequality:
                   |a_n - L| ≤ |a_n - a_{n_k}| + |a_{n_k} - L|.
               Both pieces small for n, k large.
       Conclude  a_n → L.

       [Uses completeness, via BW.]

Say: This direction is where ℝ matters. In ℚ, Cauchy sequences
need NOT converge — think of rational decimal approximations to √2,
which are Cauchy but have no rational limit. The fact that every
Cauchy sequence in ℝ converges is exactly what it means for ℝ to
be "Cauchy complete."

------------------------------------------------------------------------

Closing: The Big Picture (8:00–10:00)

Write on board:
  In ℝ, the following are EQUIVALENT (and all FAIL in ℚ):
    • Completeness Axiom (sup of bounded sets exist)
    • Monotone Convergence Theorem
    • Bolzano–Weierstrass Theorem
    • Cauchy completeness
    • Nested Intervals Property

Say: All of these are different faces of the same underlying
structural fact: ℝ has no holes. You can take any one of them as an
axiom; the others become theorems. Bauldry §2.5 lays this out
explicitly, and the Bridge Reading guides you through that
presentation.

Say: The takeaway for graduate analysis: when you see a result that
"just needs completeness," it is using one of these five faces. Get
comfortable recognizing which one is in play. That recognition is
half of what passes for analytic maturity in MAT 5610.
