VIDEO 1: Pointwise vs. Uniform Convergence (~10 min)
=============================================================

[Slide 1: Motivation]
Say: Every idea in this course has been building toward this module. We know how to talk about sequences of numbers converging. Now we ask a new question: what does it mean for a sequence of FUNCTIONS to converge? And just as importantly — when it converges, does the limit function inherit the properties we care about? The answer depends entirely on HOW the convergence happens. That's the point of this video.

[Slide 2: Pointwise Convergence — Definition]
Say: The simplest notion is pointwise convergence. The idea is: fix x, and watch what f_n(x) does as n grows.
Write on board:
  Pointwise convergence:
  f_n → f pointwise on S  if, for each fixed x in S:
    lim_{n→∞} f_n(x) = f(x)

  In quantifier form:
  ∀ x ∈ S,  ∀ ε > 0,  ∃ N (depending on x and ε)  s.t.
    n ≥ N  ⟹  |f_n(x) − f(x)| < ε

Say: The key phrase is "depending on x." For each separate x, I get a separate N. At some points the convergence is fast; at others it may be very slow. Pointwise convergence makes no promise about how these N's relate to each other across the domain.

[Slide 3: The Canonical Example — x^n on [0,1]]
Say: Here is the example you must know cold. Let f_n(x) = x^n on [0,1].
Write on board:
  f_n(x) = x^n,   x ∈ [0,1]

  For x ∈ [0,1):  |x| < 1,  so  x^n → 0
  For x = 1:       1^n = 1  for all n,  so  x^n → 1

  Pointwise limit:
      f(x) = 0   for x ∈ [0,1)
      f(1) = 1

Say: So the pointwise limit exists — it's a well-defined function. But look at it. Each f_n is continuous — it's a polynomial — and the pointwise limit is DISCONTINUOUS at x = 1. The limit function has a jump. This should bother you. We're used to limits of continuous functions being continuous. Why did that fail here? The answer is: pointwise convergence is too weak.

[Slide 4: The Sup-Norm and Uniform Convergence — Definition]
Say: Uniform convergence fixes the problem by demanding a SINGLE N that works for all x simultaneously.
Write on board:
  Uniform convergence:
  f_n → f uniformly on S  if:
  ∀ ε > 0,  ∃ N (depending only on ε)  s.t.
    n ≥ N  and  x ∈ S  ⟹  |f_n(x) − f(x)| < ε

  Equivalent criterion (sup-norm):
    f_n → f uniformly on S
    iff
    sup_{x ∈ S} |f_n(x) − f(x)| → 0 as n → ∞

Say: The ONLY change from pointwise convergence is where the "∃ N" sits — it moves outside the "∀ x." That's a quantifier swap. It sounds small. It isn't. Under uniform convergence, there's a UNIFORM envelope: the whole graph of f_n stays within ε of the graph of f, for ALL x, once n is large enough.

[Slide 5: Proving x^n is NOT Uniform on [0,1]]
Say: Let's use the sup-norm to verify that x^n does NOT converge uniformly on [0,1].
Write on board:
  sup_{x ∈ [0,1]} |f_n(x) − f(x)|
  = sup_{x ∈ [0,1)} |x^n − 0|
  = sup_{x ∈ [0,1)} x^n

[Leave the following BLANK for live work:]
% Live work:
%   As x → 1^−,  x^n → 1.
%   So sup_{x ∈ [0,1)} x^n = 1  (sup approached but not attained in (0,1))
%   At x=1: |1^n − 1| = 0  (contributes nothing)
%   Therefore: sup_{x ∈ [0,1]} |f_n(x) − f(x)| = 1  for ALL n
%   This does NOT → 0.  So convergence is NOT uniform.

Say: The supremum equals 1 for every single n — it never decreases. So the sup-norm criterion fails, and the convergence is not uniform. This is the prototypical counterexample: pointwise convergence, but not uniform, and the limit is discontinuous. Keep this example in your mind for everything else in this module.

[Slide 6: Contrast with a Uniform Example]
Say: Now let's see a case where convergence IS uniform.
Write on board:
  g_n(x) = x^n / n   on  [0, 1]

  Pointwise limit: for each fixed x in [0,1],  x^n/n ≤ 1/n → 0
  So g(x) = 0 is the pointwise limit.

  Sup-norm:
  sup_{x ∈ [0,1]} |g_n(x) − 0| = sup_{x ∈ [0,1]} x^n/n ≤ 1/n → 0

Say: Here the sup-norm goes to zero — the factor of 1/n keeps the entire graph close to zero simultaneously. So g_n converges to g=0 uniformly. Notice also that the limit is continuous here: dividing by n provided enough "damping" to prevent the crowding-near-1 behavior we saw with x^n alone.

[Slide 7: Wrap-Up]
Say: Pointwise convergence asks: at each x separately, do the values converge? Uniform convergence asks: does the whole sequence of functions approach f simultaneously, with a single error bound for all x? The difference is a quantifier swap, and it has profound consequences for what properties the limit inherits. Video 2 explores those consequences.

VIDEO 2: Consequences of Uniform Convergence (~10 min)
=============================================================

[Slide 1: The Organizing Principle]
Say: Here is the main theorem of the entire module — the organizing principle of function sequences in analysis.
Write on board:
  If f_n → f uniformly on [a,b] and each f_n is continuous,
  then:
    (1) f is continuous on [a,b]
    (2) ∫_a^b f = lim_{n→∞} ∫_a^b f_n   (interchange limit and integral)

Say: Both of these FAIL under mere pointwise convergence — we saw that with x^n. The limit was discontinuous, and the integral of the limit (which is zero) differs from the limit of the integrals (which is 1/(n+1) → 0, so actually equal in that case — but the key is continuity failed). The PROOF of (1) is the 3-epsilon trick, and you need to be able to reproduce it.

[Slide 2: Proof of (1) — The 3ε Trick]
Say: Let me sketch the proof that uniform limits of continuous functions are continuous.
Write on board:
  Fix x_0 ∈ [a,b] and ε > 0.

  Goal: find δ > 0 s.t.  |x − x_0| < δ  ⟹  |f(x) − f(x_0)| < ε

  Split:
  |f(x) − f(x_0)| ≤ |f(x) − f_N(x)| + |f_N(x) − f_N(x_0)| + |f_N(x_0) − f(x_0)|

[Leave the following BLANK for live work:]
% Live work (write the bounding of each term):
%   Term 1: uniform convergence → choose N so |f_n(x)−f(x)| < ε/3 for ALL x, all n≥N
%   Term 3: same N works at x_0, so |f_N(x_0)−f(x_0)| < ε/3
%   Term 2: f_N is continuous at x_0 → choose δ so |x−x_0|<δ ⟹ |f_N(x)−f_N(x_0)| < ε/3
%   Total: ε/3 + ε/3 + ε/3 = ε.  ∎

Say: Three things to observe. First, N is chosen BEFORE x — that's uniform convergence doing its job. Second, the δ comes from continuity of f_N, a FIXED function. Third, each of the three terms is bounded by ε/3 for a DIFFERENT reason: uniform convergence at x, continuity of f_N, and uniform convergence at x_0. This is the canonical "3-epsilon" argument. Internalize it.

[Slide 3: The Weierstrass M-Test]
Say: For SERIES of functions, we have a powerful convergence criterion called the M-Test. It's essentially a comparison test for series of functions.
Write on board:
  Weierstrass M-Test:

  Suppose:  |f_n(x)| ≤ M_n  for all x ∈ S and all n ∈ ℕ
            ∑_{n=1}^∞ M_n < ∞   (the M_n's form a convergent series)

  Conclusion:  ∑_{n=1}^∞ f_n(x)  converges absolutely and uniformly on S.

Say: The key is that M_n has no x in it — it's a uniform bound. So if you can dominate each |f_n| by a summable constant, the series converges uniformly. Example: f_n(x) = sin(nx)/n². Then |f_n(x)| ≤ 1/n² for all x, and ∑ 1/n² converges (p-series, p=2). So the series converges absolutely and uniformly on all of ℝ.

[Slide 4: M-Test Example — Power Series]
Say: The most important application of the M-Test is to power series.
Write on board:
  Power series:  ∑_{n=0}^∞ a_n x^n,   radius of convergence R

  Claim: converges UNIFORMLY on [−r, r] for any r < R.

  Bound:  |a_n x^n| ≤ |a_n| r^n =: M_n   for |x| ≤ r

  ∑ M_n = ∑ |a_n| r^n < ∞   (since r < R, the series converges absolutely at r)

  By M-Test: uniform convergence on [−r, r]. ✓

Say: This is why term-by-term integration of power series is valid — it's a corollary of the integration theorem, applied to each [0,r] with r < R.

[Slide 5: Term-by-Term Integration]
Say: Here's the integration theorem stated cleanly, and then the most famous application.
Write on board:
  Term-by-Term Integration Theorem:
  If f_n → f uniformly on [a,b] and each f_n is integrable, then:
    ∫_a^b f(x) dx  =  lim_{n→∞} ∫_a^b f_n(x) dx

  For a SERIES:  ∑ f_n → f uniformly  ⟹  ∫_a^b (∑ f_n) dx = ∑ ∫_a^b f_n dx

[Leave the following BLANK for live work:]
% Application: arctan and π/4
%   Start:  1/(1+t²) = ∑_{n=0}^∞ (−1)^n t^{2n}  for |t| < 1
%   M-Test on [0,r], r < 1:  |(−1)^n t^{2n}| ≤ r^{2n},  ∑ r^{2n} < ∞
%   Term-by-term:  arctan(x) = ∫_0^x 1/(1+t²) dt = ∑_{n=0}^∞ (−1)^n x^{2n+1}/(2n+1)
%   Set x=1 (requires Abel's theorem — stated without proof):
%     π/4 = 1 − 1/3 + 1/5 − 1/7 + ···

Say: The passage to x=1 requires a subtlety — called Abel's theorem — that goes just beyond this course. But the term-by-term integration on [0,r] for r<1 is fully rigorous right now. And the punchline — π divided by 4 equals an alternating series of unit fractions — is one of the most beautiful formulas in mathematics.

[Slide 6: What Uniform Convergence Buys — Summary]
Write on board:
  Uniform convergence of continuous functions PRESERVES:
    ✓ Continuity of the limit
    ✓ Interchange of limit and integral

  Pointwise convergence DOES NOT preserve these in general.

  The M-Test: the main tool for proving series converge uniformly.
  Power series: uniformly convergent on any [−r, r] with r < R.

Say: This is the capstone of the entire prep course. Every tool we've built — completeness, sequential convergence, continuity, integration — comes together here in the study of function spaces. MAT 5610 will spend significant time in this territory. You now have the foundation.
