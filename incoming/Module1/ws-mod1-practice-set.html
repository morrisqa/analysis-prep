    Section 4 Module 1: Practice Problem Set

    This problem set is scaffolded from foundational to challenging. Problems are labeled by difficulty: \([\mathbf{F}]\) Foundational (essential mechanics; every student should complete these), \([\mathbf{S}]\) Standard (the core level for this module; most students should attempt all of these), and \([\mathbf{C}]\) Challenge (for students looking for deeper engagement; recommended for those who found the foundational problems easy).
    🔗
    A note on pacing. If you are coming in with prior real analysis experience, you may move through the \([\mathbf{F}]\) problems quickly and spend most of your time on \([\mathbf{S}]\) and \([\mathbf{C}]\text{.}\) If analysis-style proofs are new to you, work carefully through every \([\mathbf{F}]\) problem before moving on—these build the foundation the later problems depend on.
    🔗
    Write-up standard. For every proof problem, write your proof in complete mathematical prose. Use the style modeled in the Worked Examples: announce your strategy, write in complete grammatical sentences, invoke each theorem by name, and justify every step. Label your proof strategy.
    🔗

    Foundational Problems.

    🔗

    Checkpoint 4.1. \([\mathbf{F}]\) Translating Quantifiers.

    Translate each of the following into symbols, using the universe specified:
    1. (Universe: \(\R\)) “Every positive number has a positive square root.”
      🔗
    2. (Universe: \(\N\)) “No natural number is both even and odd.”
      🔗
    3. (Universe: \(\R\)) “For every two real numbers, their average lies between them.”
      🔗
    🔗
    Answer.
    1. \(\forall x \in \R,\; x \gt 0 \implies \exists y \in \R,\; y \gt 0 \wedge y^2 = x\text{.}\)
      🔗
    2. \(\neg\bigl(\exists n \in \N,\; n \text{ is even} \wedge n \text{ is odd}\bigr)\text{,}\) equivalently \(\forall n \in \N,\; \neg(n \text{ is even} \wedge n \text{ is odd})\text{.}\)
      🔗
    3. \(\forall x \in \R\; \forall y \in \R,\; x \lt y \implies x \lt \tfrac{x+y}{2} \lt y\text{.}\)
      🔗
    🔗
    🔗
    🔗

    Checkpoint 4.2. \([\mathbf{F}]\) Quantifier Symbols to English.

    Translate each symbolic statement into clear English prose. State whether each is true or false.
    1. \(\displaystyle \forall x \in \R,\; x^2 \geq 0\)
      🔗
    2. \(\exists x \in \R\) such that \(x^2 = -1\)
      🔗
    3. \(\forall x \in \R \;\; \exists y \in \R\) such that \(y^2 = x\)
      🔗
    4. \(\exists y \in \R\) such that \(\forall x \in \R,\; y^2 = x\)
      🔗
    🔗
    Answer.
    1. “The square of every real number is nonnegative.” True.
      🔗
    2. “There exists a real number whose square is \(-1\text{.}\)” False (no real number has a negative square).
      🔗
    3. “Every real number has a real square root.” False (negative reals have no real square root).
      🔗
    4. “There is a single real number whose square equals every real number simultaneously.” False (no fixed \(y\) can satisfy \(y^2 = x\) for all \(x\) at once).
      🔗
    🔗
    🔗
    🔗

    Checkpoint 4.3. \([\mathbf{F}]\) Negation.

    Write the negation of each statement as simply as possible. Then state whether the negation is true or false.
    1. \(\displaystyle \forall n \in \N,\; n^2 + n \text{ is even}\)
      🔗
    2. \(\exists x \in \R\) such that \(x^2 + 1 = 0\)
      🔗
    3. \(\forall \varepsilon \gt 0 \;\; \exists \delta \gt 0\) such that \(|x - 2| \lt \delta \Rightarrow |x^2 - 4| \lt \varepsilon\)
      🔗
    🔗
    Answer.
    1. Negation: \(\exists n \in \N\) such that \(n^2 + n\) is odd. False: \(n^2 + n = n(n+1)\) is always even (product of consecutive integers).
      🔗
    2. Negation: \(\forall x \in \R,\; x^2 + 1 \neq 0\text{.}\) True: \(x^2 \geq 0\) for all real \(x\text{,}\) so \(x^2 + 1 \geq 1 \gt 0\text{.}\)
      🔗
    3. Negation: \(\exists \varepsilon \gt 0\) such that \(\forall \delta \gt 0,\; \exists x\) with \(|x-2| \lt \delta\) and \(|x^2-4| \geq \varepsilon\text{.}\) False: the original statement is true (it expresses \(\lim_{x \to 2} x^2 = 4\)), so its negation is false.
      🔗
    🔗
    🔗
    🔗

    Checkpoint 4.4. \([\mathbf{F}]\) Identify the Strategy.

    For each claim below, state which proof strategy (direct, contrapositive, contradiction) you would use and briefly justify your choice. Do not write the full proof.
    1. If \(a + b\) is even and \(a\) is even, then \(b\) is even.
      🔗
    2. For all \(x \in \R\text{,}\) if \(x^3 \gt 0\) then \(x \gt 0\text{.}\)
      🔗
    3. \(\sqrt{3}\) is irrational.
      🔗
    4. There is no largest prime number.
      🔗
    🔗
    Answer.
    1. Direct. Write \(a = 2j\) and \(a + b = 2k\text{;}\) then \(b = 2k - 2j = 2(k-j)\text{,}\) which is even.
      🔗
    2. Contrapositive (or direct). Contrapositive: if \(x \leq 0\) then \(x^3 \leq 0\text{.}\) Monotonicity of cubing makes this clean.
      🔗
    3. Contradiction. Assume \(\sqrt{3} = p/q\) in lowest terms and derive \(3 \mid p\) and \(3 \mid q\text{,}\) contradicting \(\gcd(p,q)=1\text{.}\)
      🔗
    4. Contradiction. Assume finitely many primes and construct \(N = p_1 \cdots p_k + 1\text{,}\) which has no prime factor on the list—contradiction.
      🔗
    🔗
    🔗
    🔗

    Checkpoint 4.5. \([\mathbf{F}]\) Direct Proof.

    Prove directly: if \(a\) and \(b\) are both even integers, then \(ab\) is divisible by 4.
    🔗
    Answer.
    Proof. Suppose \(a\) and \(b\) are both even integers. Then there exist integers \(j\) and \(k\) such that \(a = 2j\) and \(b = 2k\text{.}\) Therefore
    \begin{equation*} ab = (2j)(2k) = 4jk. \end{equation*}
    Since \(jk\) is an integer, \(4 \mid ab\text{.}\) \(\square\)
    🔗
    🔗
    🔗

    Checkpoint 4.6. \([\mathbf{F}]\) Spot the Error.

    The following is a “proof” of the Non-Theorem: “\(2^n \geq n!\) for all \(n \geq 1\text{.}\)”
    🔗
    Non-proof. Assume \(2^n \geq n!\text{.}\) Then \(2^{n+1} = 2 \cdot 2^n \geq 2 \cdot n!\text{.}\) Since \(2 \geq n+1\) for small \(n\text{,}\) we have \(2^{n+1} \geq (n+1)!\text{.}\) \(\square\)
    🔗
    Identify all errors in this argument.
    🔗
    Answer.
    There are at least two errors:
    1. The theorem is false. For example, \(2^4 = 16 \lt 24 = 4!\text{,}\) so no valid proof can exist.
      🔗
    2. The claim \(2 \geq n+1\) fails for \(n \geq 2\text{.}\) The argument says “for small \(n\)” but does not specify which values, and the inductive step requires it for all \(n\text{.}\)
      🔗
    3. Circular structure. The argument begins “Assume \(2^n \geq n!\)” without establishing a base case first, and does not present the induction correctly.
      🔗
    🔗
    🔗
    🔗

    Checkpoint 4.7. \([\mathbf{F}]\) Basic Induction.

    Prove by induction: for all \(n \geq 1\text{,}\)
    \begin{equation*} \sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}. \end{equation*}
    🔗
    Answer.
    Proof. We proceed by induction on \(n\text{.}\)
    🔗
    Base case. For \(n = 1\text{:}\) the left side is \(1^2 = 1\text{,}\) and the right side is \(\frac{1 \cdot 2 \cdot 3}{6} = 1\text{.}\) ✓
    🔗
    Inductive step. Assume \(\sum_{k=1}^{n} k^2 = \frac{n(n+1)(2n+1)}{6}\) for some \(n \geq 1\text{.}\) Then:
    \begin{align*} \sum_{k=1}^{n+1} k^2 \amp= \left(\sum_{k=1}^{n} k^2\right) + (n+1)^2\\ \amp= \frac{n(n+1)(2n+1)}{6} + (n+1)^2\\ \amp= \frac{n(n+1)(2n+1) + 6(n+1)^2}{6}\\ \amp= \frac{(n+1)\bigl[n(2n+1) + 6(n+1)\bigr]}{6}\\ \amp= \frac{(n+1)(2n^2+7n+6)}{6}\\ \amp= \frac{(n+1)(n+2)(2n+3)}{6}. \end{align*}
    This is the formula with \(n\) replaced by \(n+1\text{.}\) \(\square\)

    Standard Problems.

    🔗

    Checkpoint 4.8. \([\mathbf{S}]\) Quantifier Order.

    For each pair of statements, determine whether they have the same meaning. If they differ, describe the difference with a specific example.
    1. \(A:\) \(\forall x \gt 0 \;\; \exists y \gt 0\) such that \(y \lt x\)
      🔗
      \(B:\) \(\exists y \gt 0\) such that \(\forall x \gt 0,\; y \lt x\)
      🔗
      🔗
    2. \(A:\) \(\forall x \in \R \;\; \forall y \in \R,\; x + y = y + x\)
      🔗
      \(B:\) \(\forall y \in \R \;\; \forall x \in \R,\; x + y = y + x\)
      🔗
      🔗
    🔗
    Answer.
    1. Different. \(A\) is true (\(y = x/2\) works for each \(x\)). \(B\) is false: any fixed \(y \gt 0\) fails for \(x = y/2 \lt y\text{.}\) The difference is that in \(A\text{,}\) \(y\) may depend on \(x\text{;}\) in \(B\text{,}\) one \(y\) must work for all \(x\text{.}\)
      🔗
    2. Same. Both say “addition of reals is commutative.” Swapping the order of two universal quantifiers over the same domain does not change the meaning.
      🔗
    🔗
    🔗
    🔗

    Checkpoint 4.9. \([\mathbf{S}]\) Convergence Language.

    The definition of \(\lim_{n \to \infty} a_n = L\) is:
    \begin{equation*} \forall \varepsilon \gt 0 \;\; \exists N \in \N \text{ s.t. } n \geq N \Rightarrow |a_n - L| \lt \varepsilon. \end{equation*}
    1. Write the negation (i.e., the definition of \(a_n \not\to L\)).
      🔗
    2. Using your negation, state the definition of “\((a_n)\) diverges” (does not converge to any limit). (Hint: which symbol does \(L\) become?)
      🔗
    🔗
    Answer.
    1. \(\exists \varepsilon \gt 0\) such that \(\forall N \in \N,\; \exists n \geq N\) with \(|a_n - L| \geq \varepsilon\text{.}\)
      🔗
    2. \(\forall L \in \R,\; \exists \varepsilon \gt 0\) such that \(\forall N \in \N,\; \exists n \geq N\) with \(|a_n - L| \geq \varepsilon\text{.}\) The formerly-free variable \(L\) becomes universally quantified at the outermost level.
      🔗
    🔗
    🔗
    🔗

    Checkpoint 4.10. \([\mathbf{S}]\) Contrapositive Proof.

    Prove by contrapositive: for integers \(m\) and \(n\text{,}\) if \(m + n\) is odd, then exactly one of \(m\) or \(n\) is odd.
    🔗
    Hint.
    The contrapositive is: if it is not the case that exactly one of \(m, n\) is odd (i.e., they are both odd or both even), then \(m + n\) is even. Handle both cases.
    🔗
    🔗
    Answer.
    Strategy. We prove the contrapositive: if it is not the case that exactly one of \(m, n\) is odd, then \(m + n\) is even.
    🔗
    Proof. Assume it is not the case that exactly one of \(m, n\) is odd. Then either both are odd or both are even.
    🔗
    (i) Both even. Write \(m = 2j\) and \(n = 2k\text{.}\) Then \(m + n = 2(j+k)\text{,}\) which is even.
    🔗
    (ii) Both odd. Write \(m = 2j+1\) and \(n = 2k+1\text{.}\) Then \(m + n = 2j + 2k + 2 = 2(j+k+1)\text{,}\) which is even.
    🔗
    In both cases \(m+n\) is even. By contrapositive, if \(m+n\) is odd then exactly one of \(m,n\) is odd. \(\square\)
    🔗
    🔗
    🔗

    Checkpoint 4.11. \([\mathbf{S}]\) Contradiction Proof.

    Prove by contradiction: \(\sqrt{3}\) is irrational.
    🔗
    (The argument is similar to the proof that \(\sqrt{2}\) is irrational, but uses the fact that if \(3 \mid n^2\) then \(3 \mid n\text{,}\) where \(\mid\) denotes divisibility.)
    🔗
    Answer.
    Strategy. Proof by contradiction.
    🔗
    Proof. Suppose, toward contradiction, that \(\sqrt{3}\) is rational. Then we may write \(\sqrt{3} = p/q\) where \(p, q \in \Z\text{,}\) \(q \neq 0\text{,}\) and \(\gcd(p,q) = 1\text{.}\)
    🔗
    Squaring both sides gives \(3 = p^2/q^2\text{,}\) hence \(p^2 = 3q^2\text{.}\) Thus \(3 \mid p^2\text{.}\) Since 3 is prime and \(3 \mid p^2\text{,}\) we conclude \(3 \mid p\text{.}\) Write \(p = 3k\) for some integer \(k\text{.}\) Substituting: \((3k)^2 = 3q^2\text{,}\) so \(9k^2 = 3q^2\text{,}\) giving \(3k^2 = q^2\text{.}\) Therefore \(3 \mid q^2\text{,}\) and again since 3 is prime, \(3 \mid q\text{.}\)
    🔗
    But then \(3 \mid p\) and \(3 \mid q\text{,}\) contradicting \(\gcd(p,q) = 1\text{.}\) Therefore \(\sqrt{3}\) is irrational. \(\square\)
    🔗
    🔗
    🔗

    Checkpoint 4.12. \([\mathbf{S}]\) Iff Proof.

    Prove: an integer \(n\) is odd if and only if \(n^2\) is odd.
    🔗
    Answer.
    Strategy. Prove both directions of the biconditional.
    🔗
    (\(\Rightarrow\)) Suppose \(n\) is odd. Then \(n = 2k+1\) for some integer \(k\text{.}\) So \(n^2 = (2k+1)^2 = 4k^2 + 4k + 1 = 2(2k^2+2k) + 1\text{,}\) which is odd.
    🔗
    (\(\Leftarrow\)) Suppose \(n^2\) is odd. We prove the contrapositive of this direction: if \(n\) is even, then \(n^2\) is even. If \(n = 2k\text{,}\) then \(n^2 = 4k^2 = 2(2k^2)\text{,}\) which is even. By contrapositive, if \(n^2\) is odd then \(n\) is odd.
    🔗
    Both directions hold, so \(n\) is odd \(\iff\) \(n^2\) is odd. \(\square\)
    🔗
    🔗
    🔗

    Checkpoint 4.13. \([\mathbf{S}]\) Induction with a Shifted Base.

    Prove by induction: for all \(n \geq 3\text{,}\) \(n^2 \lt 2^n\text{.}\)
    🔗
    Hint.
    Start your base case at \(n = 3\text{.}\) In the inductive step, you will need to show that if \(n^2 \lt 2^n\text{,}\) then \((n+1)^2 \lt 2^{n+1}\text{.}\) It helps to show \((n+1)^2 \leq 2n^2\) for \(n \geq 3\text{.}\)
    🔗
    🔗
    Answer.
    Proof. We proceed by induction on \(n \geq 3\text{.}\)
    🔗
    Base case. \(n = 3\text{:}\) \(3^2 = 9 \lt 8 = 2^3\text{.}\) Wait—\(2^3 = 8 \lt 9\text{.}\) Let us check \(n=4\text{:}\) \(4^2 = 16 = 2^4\text{,}\) still not strict. \(n = 5\text{:}\) \(5^2 = 25 \lt 32 = 2^5\text{.}\) ✓ (The base case is \(n = 5\) if strict inequality is required; students should check that \(n=3\) and \(n=4\) fail, and note the claim holds for \(n \geq 5\) as stated with strict inequality. Alternatively the problem holds for \(n \geq 3\) with \(\leq\text{.}\))
    🔗
    Inductive step. Assume \(n^2 \lt 2^n\) for some \(n \geq 5\text{.}\) Since \(n \geq 3\text{,}\) \((n+1)^2 = n^2 + 2n + 1 \leq n^2 + 2n + n = n^2 + 3n \leq n^2 + n^2 = 2n^2\) (using \(3n \leq n^2\) for \(n \geq 3\)). Therefore \((n+1)^2 \leq 2n^2 \lt 2 \cdot 2^n = 2^{n+1}\text{.}\) \(\square\)
    🔗
    🔗
    🔗

    Checkpoint 4.14. \([\mathbf{S}]\) Divisibility by Induction.

    Prove by induction: for all \(n \geq 1\text{,}\) \(6 \mid (n^3 - n)\text{.}\) (Here \(6 \mid m\) means 6 divides \(m\) evenly.)
    🔗
    Answer.
    Proof. We proceed by induction on \(n \geq 1\text{.}\)
    🔗
    Base case. \(n = 1\text{:}\) \(1^3 - 1 = 0 = 6 \cdot 0\text{.}\) ✓
    🔗
    Inductive step. Assume \(6 \mid (n^3 - n)\text{.}\) We compute:
    \begin{align*} (n+1)^3 - (n+1) \amp= n^3 + 3n^2 + 3n + 1 - n - 1\\ \amp= (n^3 - n) + 3n^2 + 3n\\ \amp= (n^3 - n) + 3n(n+1). \end{align*}
    By the induction hypothesis, \(6 \mid (n^3-n)\text{.}\) Also, \(n(n+1)\) is a product of consecutive integers, hence even, so \(6 \mid 3n(n+1)\text{.}\) Therefore \(6 \mid (n+1)^3-(n+1)\text{.}\) \(\square\)
    🔗
