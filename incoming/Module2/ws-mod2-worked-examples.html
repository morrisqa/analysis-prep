    Section 3 Module 2: Worked Examples

    Read each example slowly, attending to the marginal annotations and the structure of the argument as much as to the algebra. The goal is not just to see what the answer is, but to internalize the proof strategy—particularly the template in Example 3, which you will reproduce in slightly varied form on the assessment.
    🔗

    Checkpoint 3.1. Example 1: Absolute Value Algebra.

    Solve the inequality \(|2x - 3| \lt 5\) and express the solution as an interval. Interpret the solution geometrically.
    🔗
    Solution.
    Method. We apply Theorem 1.23(c): \(|u| \lt k \iff -k \lt u \lt k\text{.}\) Here \(u = 2x - 3\) and \(k = 5\text{.}\)
    🔗
    Step 1: Convert to a compound inequality.
    \begin{align*} |2x - 3| \lt 5 \amp\iff -5 \lt 2x - 3 \lt 5\\ \amp\iff -5 + 3 \lt 2x \lt 5 + 3\\ \amp\iff -2 \lt 2x \lt 8\\ \amp\iff -1 \lt x \lt 4. \end{align*}
    🔗
    The solution set is the open interval \((-1, 4)\text{.}\)
    🔗
    Geometric interpretation. The expression \(|2x - 3| = 2|x - 3/2|\) (by the multiplicative property of absolute value). So the inequality says \(2|x - 3/2| \lt 5\text{,}\) i.e., \(|x - 3/2| \lt 5/2\text{:}\) the set of points within distance \(5/2\) of the center \(3/2\text{.}\) This gives the interval \((3/2 - 5/2, \; 3/2 + 5/2) = (-1, 4)\text{,}\) confirming our answer.
    🔗
    What to notice. The conversion rule is mechanical once you identify \(u\) and \(k\text{.}\) The geometric rewrite (center plus/minus radius) is useful for building intuition and for checking answers.

    Checkpoint 3.2. Example 2: Proving the Triangle Inequality.

    Prove: for all \(x, y \in \R\text{,}\)
    \begin{equation*} |x + y| \leq |x| + |y|. \end{equation*}
    Then deduce the reverse triangle inequality: \(\bigl||x| - |y|\bigr| \leq |x - y|\text{.}\)
    🔗
    Solution.
    Proof of the Triangle Inequality.
    🔗
    We need a key lemma first.
    🔗
    Lemma. For any \(t \in \R\text{:}\) \(-|t| \leq t \leq |t|\text{.}\)
    🔗
    Proof of Lemma. Consider two cases.
    🔗
    Case 1: \(t \geq 0\text{.}\) Then \(|t| = t\text{,}\) so the right inequality is \(t \leq t\text{,}\) which holds. For the left: \(-|t| = -t \leq 0 \leq t\text{,}\) so \(-|t| \leq t\text{.}\) □
    🔗
    Case 2: \(t \lt 0\text{.}\) Then \(|t| = -t\text{,}\) so \(-|t| = t\text{,}\) giving \(-|t| \leq t\) (equality). For the right: \(t \lt 0 \lt -t = |t|\text{,}\) so \(t \leq |t|\text{.}\) □
    🔗
    Now the main proof. Apply the Lemma to both \(x\) and \(y\text{:}\)
    \begin{gather*} -|x| \leq x \leq |x|\\ -|y| \leq y \leq |y|. \end{gather*}
    Adding these inequalities gives
    \begin{equation*} -(|x| + |y|) \leq x + y \leq |x| + |y|. \end{equation*}
    This says \(|x + y| \leq |x| + |y|\) by Theorem 1.23(c) (with \(k = |x| + |y|\)). \(\square\)
    🔗
    What to notice. The proof has three moves: (1) establish the lemma by cases, (2) apply the lemma to each variable separately, (3) add the inequalities and convert back using Theorem 1.23(c). Each step is short; the proof works because we set up the right lemma first.
    🔗
    Proof of the Reverse Triangle Inequality.
    🔗
    We want to show \(|x| - |y| \leq |x - y|\) and \(|y| - |x| \leq |x - y|\) (together these say \(\bigl||x| - |y|\bigr| \leq |x - y|\)).
    🔗
    For the first: write \(x = (x - y) + y\) and apply the Triangle Inequality:
    \begin{equation*} |x| = |(x - y) + y| \leq |x - y| + |y|. \end{equation*}
    Rearranging: \(|x| - |y| \leq |x - y|\text{.}\)
    🔗
    For the second: interchange the roles of \(x\) and \(y\) in the same argument (or use \(|x - y| = |y - x|\)):
    \begin{equation*} |y| - |x| \leq |y - x| = |x - y|. \end{equation*}
    🔗
    Since both \(|x| - |y|\) and \(|y| - |x|\) are at most \(|x - y|\text{,}\) and one of them equals \(\bigl||x| - |y|\bigr|\text{,}\) we have \(\bigl||x| - |y|\bigr| \leq |x - y|\text{.}\) \(\square\)
    🔗
    What to notice. The reverse triangle inequality is proved by applying the ordinary triangle inequality cleverly—splitting one of the absolute values as a sum and then rearranging. When you need a lower bound on \(|f(x)|\) in a proof, this inequality is often the right tool.

    Checkpoint 3.3. Example 3: Proving a Supremum.

    Let \(S = \left\{1 - \dfrac{1}{n} : n \in \N\right\}\text{.}\) Prove that \(\sup S = 1\text{.}\)
    🔗
    Solution.
    Scratch work (this section is part of the solution process; always do this before writing the proof).
    🔗
    First, note that \(S = \{0, 1/2, 2/3, 3/4, \ldots\}\text{.}\) The elements increase toward 1 but never reach it, so 1 is a natural candidate for the supremum.
    🔗
    To confirm, we need to verify two things:
    🔗
    (i) 1 is an upper bound. For all \(n \in \N\text{,}\) \(1/n \gt 0\text{,}\) so \(1 - 1/n \lt 1\text{.}\) ✓
    🔗
    (ii) 1 is the least upper bound (\(\varepsilon\)-characterization). Given \(\varepsilon \gt 0\text{,}\) we need \(n \in \N\) such that \(1 - 1/n \gt 1 - \varepsilon\text{,}\) i.e., \(1/n \lt \varepsilon\text{,}\) i.e., \(n \gt 1/\varepsilon\text{.}\) By the Archimedean Property, such \(n\) exists.
    🔗
    Now we write the formal proof.
    🔗
    Proof.
    🔗
    We show that \(1 = \sup S\) by verifying the two conditions in the definition.
    🔗
    Condition (i): 1 is an upper bound of \(S\text{.}\) Let \(x \in S\text{.}\) Then \(x = 1 - 1/n\) for some \(n \in \N\text{.}\) Since \(n \geq 1\text{,}\) we have \(1/n \leq 1\text{,}\) so \(1/n \gt 0\text{,}\) and therefore \(x = 1 - 1/n \lt 1\text{.}\) Since \(x\) was arbitrary, \(1\) is an upper bound of \(S\text{.}\)
    🔗
    Condition (ii): No number smaller than 1 is an upper bound (\(\varepsilon\)-characterization). Let \(\varepsilon \gt 0\text{.}\) We must find an element of \(S\) greater than \(1 - \varepsilon\text{.}\)
    🔗
    By the Archimedean Property, there exists \(n \in \N\) such that \(n \gt 1/\varepsilon\text{.}\) For this \(n\text{,}\) \(1/n \lt \varepsilon\text{,}\) so
    \begin{equation*} 1 - \frac{1}{n} \gt 1 - \varepsilon. \end{equation*}
    The element \(1 - 1/n\) belongs to \(S\) and exceeds \(1 - \varepsilon\text{,}\) so \(1 - \varepsilon\) is not an upper bound of \(S\text{.}\) Since \(\varepsilon \gt 0\) was arbitrary, no number strictly less than 1 is an upper bound.
    🔗
    By conditions (i) and (ii), \(1 = \sup S\text{.}\) \(\square\)
    🔗
    What to notice. This proof has a fixed template that you should internalize: first show the candidate is an upper bound, then use the \(\varepsilon\)-characterization to show nothing smaller works. The \(\varepsilon\)-characterization step always has the same shape: given \(\varepsilon \gt 0\text{,}\) exhibit a specific element of \(S\) in the interval \((s - \varepsilon, s]\text{.}\) In this example the Archimedean Property supplies that element; in other examples you may need to do more algebra to find it. The assessment asks you to apply this template to a different set.
