    Section 4 Module 2: Practice Problem Set

    Problems are labeled \([\mathbf{F}]\) (Foundational), \([\mathbf{S}]\) (Standard), and \([\mathbf{C}]\) (Challenge). Work in order within each level; later problems in a level often build on earlier ones.
    🔗
    These problems are not submitted, but you should write out complete solutions. For any problem that asks you to prove something, apply the standards from the Worked Examples: complete sentences, explicit quantifiers, every step justified.
    🔗

    Foundational Problems.

    🔗

    Checkpoint 4.1. \([\mathbf{F}]\) Absolute Value Computations.

    Compute each value. In each case, write out the definition of absolute value explicitly (i.e., note whether the argument is negative or nonnegative) before simplifying.
    1. \(\displaystyle |7 - 11|\)
      🔗
    2. \(\displaystyle |{-4} \cdot 3|\)
      🔗
    3. \(\displaystyle \left|\dfrac{-6}{2}\right|\)
      🔗
    4. \(|3 - \pi|\) (leave in terms of \(\pi\))
      🔗
    🔗
    Answer.
    (a) \(|7 - 11| = |{-4}| = 4\text{.}\) (b) \(|{-12}| = 12\text{;}\) alternatively \(|{-4}| \cdot |3| = 4 \cdot 3 = 12\text{.}\) (c) \(|{-3}| = 3\text{.}\) (d) Since \(\pi \approx 3.14159 \gt 3\text{,}\) we have \(3 - \pi \lt 0\text{,}\) so \(|3 - \pi| = \pi - 3\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.2. \([\mathbf{F}]\) Interval Translation.

    Rewrite each absolute value inequality as an interval. Identify the center and radius of each interval.
    1. \(\displaystyle |x - 5| \lt 3\)
      🔗
    2. \(\displaystyle |x + 2| \leq 1\)
      🔗
    3. \(\displaystyle |3x - 6| \lt 9\)
      🔗
    4. \(|x - a| \lt \delta\) (for \(a \in \R\) and \(\delta \gt 0\))
      🔗
    🔗
    Answer.
    (a) \(2 \lt x \lt 8\text{;}\) center 5, radius 3. (b) \(-3 \leq x \leq -1\text{;}\) center \(-2\text{,}\) radius 1. (c) \(|3(x-2)| \lt 9 \Rightarrow |x-2| \lt 3 \Rightarrow -1 \lt x \lt 5\text{;}\) center 2, radius 3. (d) \(a - \delta \lt x \lt a + \delta\text{;}\) center \(a\text{,}\) radius \(\delta\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.3. \([\mathbf{F}]\) Identifying Bounds.

    For each set, determine whether it is bounded above, bounded below, or both. If it has an upper bound, give one; if it has a lower bound, give one. Do not yet find the exact supremum or infimum.
    1. \(\displaystyle \left\{\dfrac{2}{n} : n \in \N\right\}\)
      🔗
    2. \(\displaystyle \{x \in \R : x^2 \lt 4\}\)
      🔗
    3. \(\displaystyle \{(-2)^n : n \in \N\}\)
      🔗
    4. The interval \((0, 1]\)
      🔗
    🔗
    Answer.
    (a) Bounded above by 2 (at \(n = 1\)); bounded below by 0 (all terms are positive). (b) Bounded: \(x^2 \lt 4 \Rightarrow |x| \lt 2\text{,}\) so \(-2\) is a lower bound and \(2\) is an upper bound. (c) The terms alternate sign and grow in magnitude (\(-2, 4, -8, 16, \ldots\)); neither bounded above nor below. (d) Bounded above by 1 and below by 0.
    🔗
    🔗
    🔗

    Checkpoint 4.4. \([\mathbf{F}]\) Identifying Suprema and Infima.

    For each set, identify \(\sup S\) and \(\inf S\) (if they exist). State whether the supremum or infimum is attained (i.e., belongs to \(S\)). Do not write a formal proof; a clear explanation is sufficient.
    1. \(\displaystyle S = \left\{\dfrac{2}{n} : n \in \N\right\}\)
      🔗
    2. \(\displaystyle S = \{x \in \R : x^2 \lt 4\}\)
      🔗
    3. \(\displaystyle S = (0, 1]\)
      🔗
    4. \(\displaystyle S = \left\{\dfrac{n}{n+1} : n \in \N\right\}\)
      🔗
    🔗
    Answer.
    (a) \(\sup S = 2\) (attained at \(n = 1\)); \(\inf S = 0\) (not attained; the terms approach 0). (b) \(S = (-2, 2)\text{,}\) so \(\sup S = 2\) and \(\inf S = -2\text{,}\) neither attained. (c) \(\sup S = 1\) (attained); \(\inf S = 0\) (not attained). (d) Terms are \(1/2, 2/3, 3/4, \ldots\text{,}\) increasing to 1; \(\sup S = 1\) (not attained); \(\inf S = 1/2\) (attained at \(n = 1\)).
    🔗
    🔗

    Standard Problems.

    🔗

    Checkpoint 4.5. \([\mathbf{S}]\) A Triangle Inequality Application.

    Prove that for any \(a, b, c \in \R\text{,}\)
    \begin{equation*} |a - c| \leq |a - b| + |b - c|. \end{equation*}
    This is sometimes called the metric inequality for \(\R\text{:}\) the distance from \(a\) to \(c\) is at most the sum of the distances from \(a\) to \(b\) and from \(b\) to \(c\text{.}\)
    🔗
    Hint.
    Write \(a - c = (a - b) + (b - c)\) and apply the Triangle Inequality directly.
    🔗
    🔗
    🔗

    Checkpoint 4.6. \([\mathbf{S}]\) Bounding a Product.

    Suppose \(|x - 3| \lt 1\text{.}\)
    1. Use the Triangle Inequality (or Theorem 1.23(c)) to show that \(|x + 3| \lt 7\text{.}\) (Hint: write \(x + 3 = (x - 3) + 6\text{.}\))
      🔗
    2. Using part (a), prove that \(|x^2 - 9| \lt 7 \cdot |x - 3|\text{.}\) (Hint: factor \(x^2 - 9 = (x-3)(x+3)\) and use \(|xy| = |x||y|\text{.}\))
      🔗
    3. Conclude: if \(|x - 3| \lt \min\!\left(1, \varepsilon/7\right)\text{,}\) then \(|x^2 - 9| \lt \varepsilon\text{.}\)
      🔗
    🔗
    Hint.
    For (a): \(|x + 3| = |(x-3) + 6| \leq |x-3| + 6 \lt 1 + 6 = 7\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.7. \([\mathbf{S}]\) Proving a Supremum with the \(\varepsilon\)-Characterization.

    Let \(T = \left\{\dfrac{n}{n+1} : n \in \N\right\}\text{.}\) Prove that \(\sup T = 1\text{.}\)
    🔗
    Your proof must follow the two-step structure from Worked Example 3: first show 1 is an upper bound, then use the \(\varepsilon\)-characterization to show that no smaller number is an upper bound. Include scratch work before the formal proof.
    🔗
    Hint.
    To show \(n/(n+1) \gt 1 - \varepsilon\text{,}\) rearrange to find a condition on \(n\text{,}\) then use the Archimedean Property to guarantee such \(n\) exists.
    🔗
    🔗
    🔗

    Checkpoint 4.8. \([\mathbf{S}]\) Supremum of a Set Defined by an Inequality.

    Let \(U = \{x \in \R : x^2 \leq 5\}\text{.}\)
    1. Identify \(\sup U\) and \(\inf U\text{.}\) (No proof required; explain your reasoning in one or two sentences.)
      🔗
    2. Prove your answer for \(\sup U\) by verifying both conditions in the definition of supremum. For condition (ii), you may use the fact that between any real number strictly less than \(\sqrt{5}\) and \(\sqrt{5}\) itself there exist real numbers in \(U\text{.}\) (You do not need to construct an explicit element; the density of \(\R\) near \(\sqrt{5}\) is sufficient.)
      🔗
    🔗

    Challenge Problems.

    🔗

    Checkpoint 4.9. \([\mathbf{C}]\) Uniqueness of the Supremum.

    Prove that if \(S\) is a nonempty subset of \(\R\) and both \(s\) and \(s'\) satisfy the definition of \(\sup S\text{,}\) then \(s = s'\text{.}\) In other words, the supremum, if it exists, is unique.
    🔗
    Hint.
    Since both \(s\) and \(s'\) are upper bounds of \(S\text{,}\) and both are least upper bounds, use the second condition of the definition to show \(s \leq s'\) and \(s' \leq s\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.10. \([\mathbf{C}]\) The Archimedean Property from Completeness.

    Assume the Completeness Axiom. Prove the Archimedean Property: for every \(x \in \R\text{,}\) there exists \(n \in \N\) such that \(n \gt x\text{.}\)
    🔗
    (This is the argument you will read in Bauldry as Theorem 2.3. Working through it yourself before the Bridge Reading will make Bauldry’s proof much easier to follow.)
    🔗
    Hint.
    Suppose, for contradiction, that no such \(n\) exists, i.e., that \(x\) is an upper bound for \(\N\text{.}\) Apply the Completeness Axiom to \(\N\) to obtain \(\alpha = \sup \N\text{.}\) Then consider \(\alpha - 1\text{:}\) use the \(\varepsilon\)-characterization with \(\varepsilon = 1\) to derive a contradiction.
