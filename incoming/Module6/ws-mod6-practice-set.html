    Section 4 Module 6: Practice Problem Set

    Problems are labeled \([\mathbf{F}]\) (Foundational), \([\mathbf{S}]\) (Standard), and \([\mathbf{C}]\) (Challenge). Work in order within each level; later problems in a level often build on earlier ones.
    🔗
    These problems are not submitted, but you should write out complete solutions. For any problem that asks you to prove something, apply the standards from the Worked Examples: state your strategy up front, write in complete sentences, justify every step, and cite each test or theorem by name.
    🔗
    The \(\varepsilon\)-\(\delta\) proofs will take longer than they look. Allow extra time for the scratch work phase, which is not optional—it is where you find \(\delta\text{.}\)
    🔗

    Foundational Problems.

    🔗

    Checkpoint 4.1. \([\mathbf{F}]\) Limit Intuition.

    For each, state the limit or state that it does not exist. No formal proof is required; use your calculus intuition or algebra to evaluate.
    1. \(\displaystyle \displaystyle\lim_{x \to 1} \frac{x^2 - 1}{x - 1}\)
      🔗
    2. \(\displaystyle \displaystyle\lim_{x \to 0} \frac{|x|}{x}\)
      🔗
    3. \(\displaystyle \displaystyle\lim_{x \to \infty} \frac{2x + 1}{x - 3}\)
      🔗
    4. \(\displaystyle \displaystyle\lim_{x \to 0} \frac{\sin x}{x}\)
      🔗
    🔗
    Answer.
    (a) Factor: \((x^2 - 1)/(x - 1) = x + 1 \to 2\) as \(x \to 1\text{.}\)
    🔗
    (b) For \(x \gt 0\text{,}\) \(|x|/x = 1\text{;}\) for \(x \lt 0\text{,}\) \(|x|/x = -1\text{.}\) The left and right limits disagree, so the limit does not exist.
    🔗
    (c) Divide numerator and denominator by \(x\text{:}\) \((2 + 1/x)/(1 - 3/x) \to 2/1 = 2\text{.}\)
    🔗
    (d) This is a standard limit from calculus: \(\lim_{x \to 0} \sin(x)/x = 1\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.2. \([\mathbf{F}]\) Finding \(\delta\).

    Let \(f(x) = 5x - 2\text{.}\) The limit as \(x \to 1\) is \(L = 3\text{.}\) For each given \(\varepsilon\text{,}\) find the largest valid \(\delta\) (in terms of \(\varepsilon\) for part (d)).
    1. \(\displaystyle \varepsilon = 0.5\)
      🔗
    2. \(\displaystyle \varepsilon = 0.1\)
      🔗
    3. \(\displaystyle \varepsilon = 0.01\)
      🔗
    4. General \(\varepsilon \gt 0\text{.}\)
      🔗
    🔗
    Answer.
    Note that \(|f(x) - 3| = |5x - 2 - 3| = 5|x - 1|\text{,}\) so we need \(5|x - 1| \lt \varepsilon\text{,}\) i.e., \(|x - 1| \lt \varepsilon/5\text{.}\)
    🔗
    (a) \(\delta = 0.5/5 = 0.1\text{.}\) (b) \(\delta = 0.1/5 = 0.02\text{.}\) (c) \(\delta = 0.01/5 = 0.002\text{.}\) (d) \(\delta = \varepsilon/5\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.3. \([\mathbf{F}]\) Continuity Check.

    For each function and point, determine whether \(f\) is continuous at \(a\) by checking whether \(\lim_{x \to a} f(x) = f(a)\text{.}\) State your conclusion with a brief justification.
    1. \(f(x) = x^3 - x\) at \(a = 2\text{.}\)
      🔗
    2. \(f(x) = \dfrac{x^2 - 9}{x - 3}\) at \(a = 3\text{.}\)
      🔗
    3. \(f(x) = |x|\) at \(a = 0\text{.}\)
      🔗
    4. \(f(x) = 1/x\) at \(a = 0\text{.}\)
      🔗
    🔗
    Answer.
    (a) \(f(2) = 8 - 2 = 6\text{.}\) As a polynomial, \(f\) is continuous everywhere; \(\lim_{x \to 2} f(x) = f(2) = 6\text{.}\) Continuous at \(a = 2\text{.}\)
    🔗
    (b) \(f(3)\) is undefined (division by zero), so \(f\) is not continuous at \(a = 3\text{.}\) The limit \(\lim_{x \to 3} (x^2 - 9)/(x - 3) = \lim_{x \to 3}(x + 3) = 6\) exists, but there is no value of \(f(3)\) to equal it.
    🔗
    (c) \(f(0) = 0\text{.}\) For \(x \gt 0\text{,}\) \(|x| = x \to 0\text{;}\) for \(x \lt 0\text{,}\) \(|x| = -x \to 0\text{.}\) So \(\lim_{x \to 0} |x| = 0 = f(0)\text{.}\) Continuous.
    🔗
    (d) \(f(0)\) is undefined, so \(f\) is not continuous at \(a = 0\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.4. \([\mathbf{F}]\) IVT Application.

    Show that \(x^5 - 3x + 1 = 0\) has at least one solution in \((0, 2)\text{.}\) Identify the function \(f\text{,}\) compute \(f(0)\) and \(f(2)\text{,}\) and invoke the IVT by name.
    🔗
    Answer.
    Let \(f(x) = x^5 - 3x + 1\text{.}\) As a polynomial, \(f\) is continuous on \([0, 2]\text{.}\) We compute \(f(0) = 0 - 0 + 1 = 1 \gt 0\) and \(f(2) = 32 - 6 + 1 = 27 \gt 0\text{.}\)
    🔗
    Since both endpoints give positive values, we cannot yet apply IVT directly. Check an interior point: \(f(1) = 1 - 3 + 1 = -1 \lt 0\text{.}\) Now \(f(0) = 1 \gt 0\) and \(f(1) = -1 \lt 0\text{,}\) so by the Intermediate Value Theorem, there exists \(c \in (0, 1) \subset (0, 2)\) with \(f(c) = 0\text{.}\)
    🔗
    🔗
    🔗

    Standard Problems.

    🔗

    Checkpoint 4.5. \([\mathbf{S}]\) An \(\varepsilon\)-\(\delta\) Limit Proof.

    Prove that \(\displaystyle\lim_{x \to 4} \left(\frac{x}{2} + 1\right) = 3\text{.}\)
    🔗
    Your proof must follow this structure:
    1. Scratch work. Compute \(|f(x) - 3|\) and find a value of \(\delta\) in terms of \(\varepsilon\) that will work.
      🔗
    2. Formal proof. State “Let \(\varepsilon \gt 0\)” and “Set \(\delta = \ldots\text{,}\)” assume \(0 \lt |x - 4| \lt \delta\text{,}\) and verify the chain of inequalities concluding \(|f(x) - 3| \lt \varepsilon\text{.}\)
      🔗
    🔗
    🔗

    Checkpoint 4.6. \([\mathbf{S}]\) Continuity from the Definition.

    Prove that \(f(x) = 3x + 7\) is continuous at every \(a \in \R\text{.}\)
    🔗
    Hint.
    \(|f(x) - f(a)| = |3x + 7 - (3a + 7)| = 3|x - a|\text{.}\) Set \(\delta = \varepsilon / 3\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.7. \([\mathbf{S}]\) Uniform Continuity via Lipschitz.

    Prove that \(f(x) = \sqrt{x}\) is uniformly continuous on \([1, \infty)\) by showing it satisfies a Lipschitz condition on that domain.
    🔗
    Hint.
    For \(x, y \geq 1\text{,}\) write \(|\sqrt{x} - \sqrt{y}| = |x - y| / (\sqrt{x} + \sqrt{y})\) (rationalize the numerator). Since \(x, y \geq 1\text{,}\) \(\sqrt{x} + \sqrt{y} \geq 2\text{,}\) so \(|\sqrt{x} - \sqrt{y}| \leq |x - y| / 2\text{.}\) This gives a Lipschitz constant \(K = 1/2\text{,}\) so \(\delta = 2\varepsilon\) works.
    🔗
    🔗
    🔗

    Checkpoint 4.8. \([\mathbf{S}]\) Not Uniformly Continuous.

    Prove that \(g(x) = x^2\) is not uniformly continuous on \(\R\text{.}\)
    🔗
    Hint.
    Let \(x_n = n + 1/n\) and \(y_n = n\text{.}\) Then \(|x_n - y_n| = 1/n \to 0\text{.}\) Compute \(|g(x_n) - g(y_n)| = |x_n^2 - y_n^2|\) and show this does not tend to 0.
    🔗
    🔗
    🔗

    Checkpoint 4.9. \([\mathbf{S}]\) Composition of Continuous Functions.

    State and prove: if \(f\) is continuous at \(a\) and \(g\) is continuous at \(f(a)\text{,}\) then \(g \circ f\) is continuous at \(a\text{.}\)
    🔗
    You may use the sequential characterization of continuity for both \(f\) and \(g\text{.}\)
    🔗
    Hint.
    Let \((x_n)\) be any sequence with \(x_n \to a\text{.}\) Since \(f\) is continuous at \(a\text{,}\) \(f(x_n) \to f(a)\text{.}\) Since \(g\) is continuous at \(f(a)\) and \(f(x_n) \to f(a)\text{,}\) we get \(g(f(x_n)) \to g(f(a))\text{.}\) That is, \((g \circ f)(x_n) \to (g \circ f)(a)\) for every sequence \(x_n \to a\text{,}\) so \(g \circ f\) is continuous at \(a\text{.}\)
    🔗
    🔗
    🔗

    Challenge Problems.

    🔗

    Checkpoint 4.10. \([\mathbf{C}]\) Uniformly Continuous Functions Extend to the Boundary.

    Prove: if \(f : (a, b) \to \R\) is uniformly continuous, then both limits \(\lim_{x \to a^+} f(x)\) and \(\lim_{x \to b^-} f(x)\) exist. (That is, \(f\) extends continuously to the closed interval \([a, b]\text{.}\))
    🔗
    Hint.
    Let \((x_n)\) be any sequence in \((a, b)\) with \(x_n \to a\text{.}\) Show that \((f(x_n))\) is a Cauchy sequence using the definition of uniform continuity: given \(\varepsilon \gt 0\text{,}\) pick \(\delta \gt 0\) from uniform continuity; since \(x_n \to a\text{,}\) eventually \(|x_m - x_n| \lt \delta\text{,}\) so \(|f(x_m) - f(x_n)| \lt \varepsilon\text{.}\) By Cauchy completeness of \(\R\) (Module 4), \(f(x_n)\) converges. One then checks that every sequence approaching \(a\) gives the same limit, which defines \(\lim_{x \to a^+} f(x)\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.11. \([\mathbf{C}]\) Composition of Uniformly Continuous Functions.

    Prove: if \(f : A \to B\) is uniformly continuous and \(g : B \to \R\) is uniformly continuous, then \(g \circ f : A \to \R\) is uniformly continuous.
    🔗
    Hint.
    Given \(\varepsilon \gt 0\text{,}\) use uniform continuity of \(g\) to find \(\delta_1 \gt 0\) such that \(|u - v| \lt \delta_1 \Rightarrow |g(u) - g(v)| \lt \varepsilon\) for all \(u, v \in B\text{.}\) Then use uniform continuity of \(f\) with \(\varepsilon' = \delta_1\) to find \(\delta \gt 0\) such that \(|x - y| \lt \delta \Rightarrow |f(x) - f(y)| \lt \delta_1\) for all \(x, y \in A\text{.}\) Chain the two implications.
    🔗
