    Section 3 Module 6: Worked Examples

    Read each example slowly. The goal is not just to see what the answer is, but to internalize the proof template. Example 1 is the archetype of an \(\varepsilon\)-\(\delta\) limit proof; Example 2 shows how to prove continuity at every point of \(\R\) using the same method; Example 3 demonstrates the sequential technique for proving non-uniform continuity; Example 4 shows the Lipschitz method for proving uniform continuity on a bounded interval.
    🔗

    Checkpoint 3.1. Example 1: An \(\varepsilon\)-\(\delta\) Limit Proof.

    Prove that \(\lim_{x \to 2} (3x - 1) = 5\text{.}\)
    🔗
    Solution.
    Strategy.
    🔗
    We use the \(\varepsilon\)-\(\delta\) definition directly. The proof has two phases: scratch work to find \(\delta\) in terms of \(\varepsilon\text{,}\) and a formal proof that verifies that choice works.
    🔗
    Scratch work.
    🔗
    We need \(|f(x) - 5| \lt \varepsilon\) when \(0 \lt |x - 2| \lt \delta\text{.}\) Compute:
    \begin{equation*} |f(x) - 5| = |(3x - 1) - 5| = |3x - 6| = 3|x - 2|. \end{equation*}
    For this to be less than \(\varepsilon\text{,}\) we need \(3|x - 2| \lt \varepsilon\text{,}\) i.e., \(|x - 2| \lt \varepsilon / 3\text{.}\) Set \(\delta = \varepsilon / 3\text{.}\)
    🔗
    Proof.
    🔗
    Let \(\varepsilon \gt 0\text{.}\) Set \(\delta = \varepsilon / 3\text{.}\) Suppose \(0 \lt |x - 2| \lt \delta\text{.}\) Then
    \begin{equation*} |f(x) - 5| = |(3x - 1) - 5| = 3|x - 2| \lt 3\delta = \varepsilon. \end{equation*}
    By the definition of limit, \(\lim_{x \to 2} (3x - 1) = 5\text{.}\) \(\square\)
    🔗
    What to notice.
    🔗
    The scratch work determines \(\delta\text{;}\) the formal proof simply verifies the chain of inequalities. This two-phase structure is the standard template for all \(\varepsilon\)-\(\delta\) proofs. Notice that in this linear example the expression \(|f(x) - L|\) simplified to a constant times \(|x - a|\) immediately. In Example 2, the function is quadratic and we need an extra step to bound the remaining factor.
    🔗

    Checkpoint 3.2. Example 2: Proving Continuity Using the \(\varepsilon\)-\(\delta\) Definition.

    Prove that \(f(x) = x^2\) is continuous at every \(a \in \R\text{.}\)
    🔗
    Solution.
    Strategy.
    🔗
    We must show \(|x^2 - a^2| \lt \varepsilon\) whenever \(|x - a| \lt \delta\text{.}\) The key is to factor \(|x^2 - a^2| = |x - a| \cdot |x + a|\) and bound \(|x + a|\) by first restricting \(|x - a| \lt 1\text{.}\)
    🔗
    Scratch work.
    🔗
    Restrict \(|x - a| \lt 1\) first. Then \(|x| \lt |a| + 1\text{,}\) so \(|x + a| \leq |x| + |a| \lt 2|a| + 1\text{.}\) Therefore
    \begin{equation*} |x^2 - a^2| = |x - a| \cdot |x + a| \lt (2|a| + 1) \cdot |x - a|. \end{equation*}
    For this to be less than \(\varepsilon\text{,}\) we need \(|x - a| \lt \varepsilon / (2|a| + 1)\text{.}\) Set \(\delta = \min(1,\, \varepsilon / (2|a| + 1))\text{.}\)
    🔗
    Proof.
    🔗
    Let \(\varepsilon \gt 0\text{.}\) Set \(\delta = \min(1,\, \varepsilon / (2|a| + 1))\text{.}\) Suppose \(|x - a| \lt \delta\text{.}\) Since \(\delta \leq 1\text{,}\) we have \(|x - a| \lt 1\text{,}\) which gives \(|x| \lt |a| + 1\) and hence \(|x + a| \leq |x| + |a| \lt 2|a| + 1\text{.}\) Therefore
    \begin{equation*} |x^2 - a^2| = |x - a| \cdot |x + a| \lt \delta \cdot (2|a| + 1) \leq \frac{\varepsilon}{2|a| + 1} \cdot (2|a| + 1) = \varepsilon. \end{equation*}
    Since \(a \in \R\) was arbitrary, \(f(x) = x^2\) is continuous at every \(a \in \R\text{.}\) \(\square\)
    🔗
    What to notice.
    🔗
    The “restrict to a neighborhood first” step is the essential technical move in continuity proofs for nonlinear functions. By requiring \(|x - a| \lt 1\text{,}\) we get a bound on \(|x + a|\) that does not blow up. Note that \(\delta\) depends on both \(\varepsilon\) and \(a\text{;}\) this is perfectly fine for continuity (pointwise). The same function \(x^2\) is not uniformly continuous on \(\R\text{,}\) because the factor \(2|a| + 1\) grows without bound as \(|a| \to \infty\text{,}\) so no single \(\delta\) works for all points. On any bounded interval, however, \(2|a| + 1\) is bounded above, and uniform continuity follows (see Example 4).
    🔗
    🔗

    Checkpoint 3.3. Example 3: Proving \(f(x) = 1/x\) is Not Uniformly Continuous on \((0,1)\).

    Prove that \(f(x) = 1/x\) is not uniformly continuous on \((0, 1)\text{.}\)
    🔗
    Solution.
    Strategy.
    🔗
    To negate uniform continuity, we must exhibit \(\varepsilon_0 \gt 0\) such that for every \(\delta \gt 0\text{,}\) there exist \(x, y \in (0, 1)\) with \(|x - y| \lt \delta\) but \(|f(x) - f(y)| \geq \varepsilon_0\text{.}\) The cleanest way is to produce explicit sequences with \(|x_n - y_n| \to 0\) but \(|f(x_n) - f(y_n)| \not\to 0\text{.}\)
    🔗
    Proof.
    🔗
    Let \(x_n = 1/n\) and \(y_n = 1/(n + 1)\) for \(n \geq 2\text{.}\) Both sequences lie in \((0, 1)\) and we compute
    \begin{equation*} |x_n - y_n| = \frac{1}{n} - \frac{1}{n+1} = \frac{1}{n(n+1)} \to 0. \end{equation*}
    However,
    \begin{equation*} |f(x_n) - f(y_n)| = |n - (n + 1)| = 1 \end{equation*}
    for all \(n \geq 2\text{.}\) Therefore \(|f(x_n) - f(y_n)| = 1 \not\to 0\text{.}\)
    🔗
    To make the argument formal: take \(\varepsilon_0 = 1/2\text{.}\) For any \(\delta \gt 0\text{,}\) choose \(n\) large enough that \(1/(n(n+1)) \lt \delta\text{.}\) Then \(x_n, y_n \in (0,1)\) satisfy \(|x_n - y_n| \lt \delta\) but \(|f(x_n) - f(y_n)| = 1 \geq \varepsilon_0\text{.}\) Since \(\delta \gt 0\) was arbitrary, no single \(\delta\) works for this \(\varepsilon_0\text{,}\) and \(f\) is not uniformly continuous on \((0, 1)\text{.}\) \(\square\)
    🔗
    What to notice.
    🔗
    The negation of uniform continuity (\(\exists \varepsilon_0 \gt 0\ \forall \delta \gt 0\ \exists x, y \in S: |x - y| \lt \delta \text{ and } |f(x) - f(y)| \geq \varepsilon_0\)) is most cleanly verified with an explicit pair of sequences. The key is that \(x_n\) and \(y_n\) both approach 0 (where \(1/x\) blows up), so the function values diverge even though the inputs become arbitrarily close.
    🔗
    🔗
    🔗

    Checkpoint 3.4. Example 4: Uniform Continuity via a Lipschitz Condition.

    Prove that \(f(x) = x^2\) is uniformly continuous on \([0, 2]\text{.}\)
    🔗
    Solution.
    Strategy.
    🔗
    On the bounded closed interval \([0, 2]\text{,}\) we can bound \(|x + y|\) uniformly for all \(x, y \in [0, 2]\text{.}\) This gives a Lipschitz condition \(|f(x) - f(y)| \leq K|x - y|\) with a fixed constant \(K\text{,}\) which immediately implies uniform continuity with \(\delta = \varepsilon / K\text{.}\)
    🔗
    Proof.
    🔗
    For any \(x, y \in [0, 2]\text{,}\)
    \begin{equation*} |f(x) - f(y)| = |x^2 - y^2| = |x + y| \cdot |x - y|. \end{equation*}
    Since \(x, y \in [0, 2]\text{,}\) we have \(|x + y| \leq |x| + |y| \leq 2 + 2 = 4\text{.}\) Therefore
    \begin{equation*} |f(x) - f(y)| \leq 4|x - y|. \end{equation*}
    This is a Lipschitz condition with constant \(K = 4\text{.}\) Given \(\varepsilon \gt 0\text{,}\) set \(\delta = \varepsilon / 4\text{.}\) Then for all \(x, y \in [0, 2]\) with \(|x - y| \lt \delta\text{,}\)
    \begin{equation*} |f(x) - f(y)| \leq 4|x - y| \lt 4\delta = \varepsilon. \end{equation*}
    Since the same \(\delta\) works for all \(x, y \in [0, 2]\text{,}\) \(f\) is uniformly continuous on \([0, 2]\text{.}\) \(\square\)
    🔗
    What to notice.
    🔗
    The Lipschitz constant \(K = 4\) comes from the global bound \(|x + y| \leq 4\) on \([0, 2]\text{.}\) On all of \(\R\text{,}\) no such global bound exists (as \(|a| \to \infty\text{,}\) \(|x + a|\) can be made arbitrarily large), which is why \(x^2\) is not uniformly continuous on \(\R\text{.}\) The Heine–Cantor theorem explains why boundedness and closedness together guarantee uniform continuity: every continuous function on a compact set is Lipschitz on that set (or at least uniformly continuous, which Heine–Cantor guarantees even without a Lipschitz bound). The proof of Heine–Cantor is a topic for MAT 5610.
