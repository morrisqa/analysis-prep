    Section 4 Module 5: Practice Problem Set

    Problems are labeled \([\mathbf{F}]\) (Foundational), \([\mathbf{S}]\) (Standard), and \([\mathbf{C}]\) (Challenge). Work in order within each level; later problems in a level often build on earlier ones.
    🔗
    These problems are not submitted, but you should write out complete solutions. For any problem that asks you to prove something, apply the standards from the Worked Examples: strategy stated up front, complete sentences, every step justified, and the test or theorem invoked by name.
    🔗

    Foundational Problems.

    🔗

    Checkpoint 4.1. \([\mathbf{F}]\) Partial Sums by Hand.

    For each series, write out \(S_1, S_2, S_3, S_4\) as fractions. Then guess (no proof required) whether the series converges and, if so, to what.
    1. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \frac{1}{3^{k-1}}\)
      🔗
    2. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \frac{1}{k(k+1)}\)
      🔗
    3. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} (-1)^{k+1}\)
      🔗
    🔗
    Answer.
    (a) \(S_1 = 1\text{,}\) \(S_2 = 4/3\text{,}\) \(S_3 = 13/9\text{,}\) \(S_4 = 40/27\text{;}\) approaches \(3/2\) (geometric, ratio \(1/3\)). (b) \(S_1 = 1/2\text{,}\) \(S_2 = 2/3\text{,}\) \(S_3 = 3/4\text{,}\) \(S_4 = 4/5\text{;}\) approaches 1 (telescoping, cf. Worked Example 1). (c) \(S_1 = 1\text{,}\) \(S_2 = 0\text{,}\) \(S_3 = 1\text{,}\) \(S_4 = 0\text{;}\) oscillates, diverges.
    🔗
    🔗
    🔗

    Checkpoint 4.2. \([\mathbf{F}]\) Geometric Series.

    For each series, determine whether it converges, and if so compute its sum. Identify the first term \(a\) and common ratio \(r\text{,}\) then apply the geometric-series formula \(a/(1 - r)\text{.}\)
    1. \(\displaystyle \displaystyle\sum_{k=0}^{\infty} 3 \cdot \left(\frac{1}{4}\right)^{k}\)
      🔗
    2. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \left(\frac{2}{3}\right)^{k}\)
      🔗
    3. \(\displaystyle \displaystyle\sum_{k=0}^{\infty} \left(-\frac{1}{2}\right)^{k}\)
      🔗
    4. \(\displaystyle \displaystyle\sum_{k=0}^{\infty} \left(\frac{5}{3}\right)^{k}\)
      🔗
    🔗
    Answer.
    (a) \(a = 3\text{,}\) \(r = 1/4\text{;}\) sum \(= 3/(1 - 1/4) = 4\text{.}\) (b) First term \(2/3\text{,}\) ratio \(2/3\text{;}\) sum \(= (2/3)/(1 - 2/3) = 2\text{.}\) (c) \(a = 1\text{,}\) \(r = -1/2\text{;}\) sum \(= 1/(1 - (-1/2)) = 2/3\text{.}\) (d) \(|r| = 5/3 \gt 1\text{;}\) diverges.
    🔗
    🔗
    🔗

    Checkpoint 4.3. \([\mathbf{F}]\) The Divergence Test.

    Use the Divergence Test to show that each of the following series diverges, or state that the test is inconclusive.
    1. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \frac{k}{k + 1}\)
      🔗
    2. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \frac{1}{k}\)
      🔗
    3. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} (-1)^{k+1} \frac{k}{k + 1}\)
      🔗
    4. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \cos\!\left(\frac{1}{k}\right)\)
      🔗
    🔗
    Answer.
    (a) \(a_k = k/(k+1) \to 1 \neq 0\text{;}\) diverges. (b) \(a_k = 1/k \to 0\text{;}\) Divergence Test is inconclusive. (The harmonic series does diverge, but by a different argument.) (c) \(|a_k| = k/(k+1) \to 1\text{,}\) so \(a_k \not\to 0\) (the terms oscillate between values close to \(\pm 1\)); diverges. (d) \(\cos(1/k) \to \cos(0) = 1 \neq 0\text{;}\) diverges.
    🔗
    🔗
    🔗

    Checkpoint 4.4. \([\mathbf{F}]\) Direct Comparison.

    Use the Direct Comparison Test to determine convergence or divergence of each series. Identify the “known” series you are comparing to.
    1. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \frac{1}{k^2 + 3}\)
      🔗
    2. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \frac{2}{\sqrt{k}}\)
      🔗
    3. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \frac{1}{2^k + k}\)
      🔗
    🔗
    Answer.
    (a) \(1/(k^2 + 3) \leq 1/k^2\text{,}\) and \(\sum 1/k^2\) converges; so \(\sum 1/(k^2 + 3)\) converges. (b) \(2/\sqrt{k} \geq 2/k\) for \(k \geq 1\) (since \(\sqrt{k} \leq k\)); \(\sum 2/k\) diverges; so \(\sum 2/\sqrt{k}\) diverges. (c) \(1/(2^k + k) \leq 1/2^k\text{;}\) \(\sum 1/2^k\) converges (geometric); so \(\sum 1/(2^k + k)\) converges.
    🔗
    🔗

    Standard Problems.

    🔗

    Checkpoint 4.5. \([\mathbf{S}]\) A Telescoping Proof.

    Prove directly from the definition of series convergence that
    \begin{equation*} \sum_{k=1}^{\infty} \frac{1}{(2k - 1)(2k + 1)} = \frac{1}{2}. \end{equation*}
    🔗
    Your proof must follow the template of Worked Example 1: (i) identify a partial-fraction decomposition of the summand; (ii) find a closed form for the partial sum \(S_n\) by telescoping; (iii) take the limit using the Algebra of Limits.
    🔗
    Hint.
    Verify that
    \begin{equation*} \frac{1}{(2k - 1)(2k + 1)} = \frac{1}{2} \left(\frac{1}{2k - 1} - \frac{1}{2k + 1}\right). \end{equation*}
    Then \(S_n = \frac{1}{2}\left(1 - \frac{1}{2n + 1}\right)\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.6. \([\mathbf{S}]\) Ratio Test Applications.

    Use the Ratio Test to determine convergence or divergence of each series. Show the ratio computation explicitly.
    1. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \frac{k}{2^k}\)
      🔗
    2. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \frac{3^k}{k!}\)
      🔗
    3. \(\displaystyle \displaystyle\sum_{k=1}^{\infty} \frac{k^2}{k!}\)
      🔗
    🔗
    Answer.
    (a) Ratio \(= (k+1)/2^{k+1} \cdot 2^k/k = (k+1)/(2k) \to 1/2 \lt 1\text{;}\) converges. (b) Ratio \(= 3^{k+1}/(k+1)! \cdot k!/3^k = 3/(k+1) \to 0 \lt 1\text{;}\) converges. (c) Ratio \(= (k+1)^2/(k+1)! \cdot k!/k^2 = (k+1)/k^2 \to 0 \lt 1\text{;}\) converges.
    🔗
    🔗
    🔗

    Checkpoint 4.7. \([\mathbf{S}]\) Limit Comparison.

    Use the Limit Comparison Test to determine convergence or divergence of
    \begin{equation*} \sum_{k=1}^{\infty} \frac{3k^2 + 1}{k^4 + 7k + 2}. \end{equation*}
    🔗
    Identify your comparison series, compute the ratio of terms, evaluate its limit, and invoke the test by name.
    🔗
    Hint.
    Leading-order behavior is \(3k^2/k^4 = 3/k^2\text{;}\) compare with \(\sum 1/k^2\text{.}\) The ratio limit is 3.
    🔗
    🔗
    🔗

    Checkpoint 4.8. \([\mathbf{S}]\) An Alternating Series.

    Prove that
    \begin{equation*} \sum_{k=1}^{\infty} \frac{(-1)^{k+1}}{k^2 + 1} \end{equation*}
    converges. Does it converge absolutely or conditionally? Justify your answer in full.
    🔗
    Your proof should (i) verify both hypotheses of the Alternating Series Test; (ii) separately investigate absolute convergence by testing \(\sum |a_k|\text{;}\) (iii) conclude with a classification.
    🔗
    Hint.
    For AST: \(b_k = 1/(k^2 + 1)\) is positive, decreasing (since \(k^2 + 1 \lt (k+1)^2 + 1\)), and tends to 0. For absolute: \(\sum 1/(k^2 + 1)\) converges by direct comparison with \(\sum 1/k^2\text{.}\) Hence the series converges absolutely.
    🔗
    🔗
    🔗

    Checkpoint 4.9. \([\mathbf{S}]\) The Divergence Test is One-Way.

    Give one example of a series \(\sum a_k\) with \(a_k \to 0\) that converges, and one example with \(a_k \to 0\) that diverges. For each, cite the reason for convergence or divergence.
    🔗
    Use this pair of examples to explain, in your own words, why the Divergence Test has the one-way structure “if \(a_k \not\to 0\text{,}\) then \(\sum a_k\) diverges” and not the stronger two-way statement.
    🔗
    Answer.
    Convergent with terms \(\to 0\text{:}\) \(\sum 1/k^2\) (\(p\)-series, \(p = 2 \gt 1\)). Divergent with terms \(\to 0\text{:}\) \(\sum 1/k\) (harmonic; see Study Guide). The pair shows that \(a_k \to 0\) is necessary (because convergent sequences of partial sums force their differences to 0) but not sufficient: the rate at which \(a_k \to 0\) determines whether the partial sums stay bounded, and for \(1/k\) they do not.
    🔗
    🔗

    Challenge Problems.

    🔗

    Checkpoint 4.10. \([\mathbf{C}]\) Absolute Convergence Implies Convergence.

    Prove: if \(\sum_{k=1}^{\infty} |a_k|\) converges, then \(\sum_{k=1}^{\infty} a_k\) converges.
    🔗
    Your proof must use the Cauchy criterion for sequences (Module 4). Let \(T_n = \sum_{k=1}^{n} |a_k|\) and \(S_n = \sum_{k=1}^{n} a_k\text{.}\) Use that \((T_n)\) is Cauchy (it converges by hypothesis) together with the triangle inequality on finite sums to show \((S_n)\) is Cauchy, and invoke Cauchy completeness of \(\R\text{.}\)
    🔗
    Hint.
    Let \(\varepsilon \gt 0\text{.}\) Since \((T_n)\) converges, it is Cauchy: there is \(N\) with \(|T_n - T_m| \lt \varepsilon\) for \(n \gt m \geq N\text{.}\) Note \(T_n - T_m = \sum_{k = m+1}^{n} |a_k|\text{.}\) Then
    \begin{equation*} |S_n - S_m| = \left|\sum_{k=m+1}^{n} a_k\right| \leq \sum_{k=m+1}^{n} |a_k| = T_n - T_m \lt \varepsilon. \end{equation*}
    Hence \((S_n)\) is Cauchy, hence convergent in \(\R\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.11. \([\mathbf{C}]\) A Series That Needs the Root Test.

    Consider the series
    \begin{equation*} \sum_{k=1}^{\infty} a_k, \qquad a_k = \begin{cases} 2^{-k}, \amp k \text{ even}, \\ 3^{-k}, \amp k \text{ odd}. \end{cases} \end{equation*}
    🔗
    1. Compute \(\lim_{k \to \infty} a_{k+1}/a_k\) if it exists. What does the Ratio Test say?
      🔗
    2. Compute \(\lim_{k \to \infty} \sqrt[k]{a_k}\text{.}\) What does the Root Test say?
      🔗
    3. Which test was decisive here, and why? What does this tell you about the relative strength of the Root and Ratio Tests?
      🔗
    🔗
    Hint.
    (a) The ratio \(a_{k+1}/a_k\) oscillates: for \(k\) odd, \(a_{k+1}/a_k = 2^{-(k+1)}/3^{-k} = 3^k/2^{k+1}\text{,}\) which grows without bound; for \(k\) even, \(a_{k+1}/a_k = 3^{-(k+1)}/2^{-k} = 2^k/3^{k+1}\text{,}\) which tends to 0. The limit does not exist; Ratio Test inconclusive. (b) For \(k\) even, \(\sqrt[k]{a_k} = 1/2\text{;}\) for \(k\) odd, \(\sqrt[k]{a_k} = 1/3\text{.}\) These are bounded above by \(1/2 \lt 1\text{;}\) a more careful version of the Root Test (using \(\limsup\)) concludes convergence. Less formally: every term satisfies \(a_k \leq 1/2^k\text{,}\) and \(\sum 1/2^k\) converges. (c) The Root Test (with \(\limsup\)) is strictly more powerful: it can handle series where the ratio oscillates but the \(k\)th root still stays bounded.
