MODULE 3: SETS, FUNCTIONS, AND CARDINALITY
Video Lecture Outlines — Instructor Reference
Two Lightboard Videos

VIDEO 1: SETS AND FUNCTIONS (~9 min)
Sources: Zorn §1.2–1.3; Hirst Ch. 5 §5.1–5.4

Core message: A set is a collection governed by axioms; a function is a
three-part package (domain, codomain, rule). Injectivity and surjectivity
are quantified statements that admit formal proof — not just pictures.

------------------------------------------------------------------------

OPENING (1 min)

Write on the board: A ∩ (B ∪ C). Ask: what is this? Most students know
it as a set operation. Today's goal: make that intuition rigorous enough
to PROVE set equalities. Motivation: every definition in analysis is
written in set language.

------------------------------------------------------------------------

SETS: NOTATION AND OPERATIONS (2 min)

Walk through the basic notation quickly, emphasizing what is new:

• Membership: x ∈ A (either true or false — no ambiguity).

• Subset: A ⊆ B means ∀x (x ∈ A ⇒ x ∈ B). Write this as a quantified
  statement explicitly.

• Union, intersection, difference, Cartesian product: state definitions
  in set-builder form. Example:
    A ∩ B = {x : x ∈ A and x ∈ B}.

• The element-chasing template: to prove A = B, show A ⊆ B and B ⊆ A
  separately. Write the two-step template on the board.

  Quick example: sketch the proof that A ∩ B = B ∩ A using this template
  (one direction only, to illustrate).

------------------------------------------------------------------------

FUNCTIONS: THE THREE-PART PACKAGE (3 min)

Emphasize: a function f : A → B is not just a formula. It consists of:
  (1) a domain A,
  (2) a codomain B,
  (3) a rule assigning each a ∈ A exactly one f(a) ∈ B.
Write this out carefully.

Range vs. codomain: the range is {f(a) : a ∈ A} ⊆ B. The codomain is B.
These need not be equal. Example: f : ℝ → ℝ, f(x) = x². Codomain is ℝ;
range is [0, ∞).

Injective (one-to-one): f(a₁) = f(a₂) ⇒ a₁ = a₂.
Equivalent contrapositive: a₁ ≠ a₂ ⇒ f(a₁) ≠ f(a₂).
Write both on the board.
  • Illustrate: f(x) = 2x + 1 is injective.
  • g(x) = x² is not (because g(−1) = g(1) = 1).

Surjective (onto): ∀b ∈ B, ∃a ∈ A, f(a) = b. The range equals the codomain.
  • f(x) = 2x + 1 is surjective onto ℝ.
  • f(x) = x² is not surjective onto ℝ.

Bijective: injective AND surjective. Equivalent to having an inverse function.
State this and move on — the next video will use bijections to define
cardinality.

------------------------------------------------------------------------

COMPOSITION (2 min)

If f : A → B and g : B → C, then g ∘ f : A → C is defined by
  (g ∘ f)(a) = g(f(a)).
Order matters: f goes first.
Write the diagram A →[f]→ B →[g]→ C on the board.

Key fact (state without proof here; proved in Worked Example 3):
If f and g are both injective, then g ∘ f is injective.
Same for surjective. (Zorn Theorem 1.10; Hirst Exercise 5.3.)

------------------------------------------------------------------------

CLOSING (1 min)

Transition: everything in the next video uses bijections to compare the
sizes of infinite sets. That is where the real surprises are.

VIDEO 2: CARDINALITY (~9 min)
Sources: Zorn §1.6; Hirst §5.5

Core message: Two sets have the same cardinality if there is a bijection
between them. The rationals are countable; the reals are not. The proof
of uncountability is Cantor's diagonal argument.

------------------------------------------------------------------------

OPENING: WHAT IS "SAME SIZE"? (1 min)

Ask: do ℕ and ℤ have the same number of elements? Common answer: no,
because ℤ contains all of ℕ plus the negative integers. The answer is
actually: YES. This motivates the formal definition.

------------------------------------------------------------------------

CARDINALITY VIA BIJECTION (2 min)

Definition: A ~ B (same cardinality) if there exists a bijection f : A → B.
This is an equivalence relation.

Finite: A is finite if A = ∅ or A ~ {1, 2, …, n} for some n ∈ ℕ.

Countably infinite: A ~ ℕ. Countable: finite or countably infinite.

Example: ℤ ~ ℕ. Write the explicit bijection:
  f(n) = n/2           if n is even
  f(n) = −(n+1)/2      if n is odd

Walk through: f(0) = 0, f(1) = −1, f(2) = 1, f(3) = −2, …
This is a bijection ℕ₀ → ℤ. The point: ℤ is countable.

------------------------------------------------------------------------

ℚ IS COUNTABLE: DIAGONAL ENUMERATION (2 min)

Draw the grid of positive rationals: rows indexed by denominators 1, 2, 3, …;
columns by numerators 1, 2, 3, …

The diagonal path visits every entry (skipping repeats). This gives an
injection ℚ⁺ → ℕ; by Prop. 1.17, ℚ⁺ is countably infinite. Extending
to all of ℚ by the same interleaving as for ℤ: ℚ is countable (Zorn Cor. 1.20).

------------------------------------------------------------------------

ℝ IS UNCOUNTABLE: CANTOR'S DIAGONAL ARGUMENT (3 min)

This is the main event. Proceed carefully.

Suppose for contradiction that (0,1) is countable, so we can list its
elements: r₁, r₂, r₃, …, where each rᵢ has a decimal expansion.

Write the list as a grid (rows = numbers, columns = decimal digits):
  r₁ = 0 . d₁₁  d₁₂  d₁₃  …
  r₂ = 0 . d₂₁  d₂₂  d₂₃  …
  r₃ = 0 . d₃₁  d₃₂  d₃₃  …

Construct the diagonal number x = 0 . x₁ x₂ x₃ … by choosing:
  xᵢ = 5    if dᵢᵢ ≠ 5
  xᵢ = 6    if dᵢᵢ = 5
(Choosing 5 and 6 avoids the 0.999… = 1.000… ambiguity.)

Then:
  • x ∈ (0,1) (clearly).
  • x ≠ rᵢ for every i, because x differs from rᵢ in the i-th decimal place.

This contradicts the assumption that the list contains all of (0,1).
Therefore (0,1) is uncountable, and since (0,1) ⊆ ℝ, ℝ is uncountable.

------------------------------------------------------------------------

CLOSING (1 min)

Emphasize the logical structure: a bijection-based assumption about an
infinite set leads to a contradiction via an explicit construction. This
template reappears in logic (Gödel's incompleteness), computability (the
halting problem), and elsewhere. Recognizing it is part of mathematical
maturity.
