    Section 4 Module 3: Practice Problem Set

    Problems are labeled \([\mathbf{F}]\) (Foundational), \([\mathbf{S}]\) (Standard), and \([\mathbf{C}]\) (Challenge). Work in order within each level; later problems in a level often build on earlier ones.
    🔗
    These problems are not submitted, but you should write out complete solutions. For any problem that asks you to prove something, apply the standards from the Worked Examples: complete sentences, quantifiers stated explicitly, every step justified.
    🔗

    Foundational Problems.

    🔗

    Checkpoint 4.1. \([\mathbf{F}]\) Set Operations.

    Let \(A = \{n \in \Z : n \text{ is even}\}\text{,}\) \(B = \{n \in \Z : n \text{ is a multiple of } 3\}\text{,}\) and \(C = \{n \in \Z : n \gt 0\}\text{.}\)
    1. Is \(6 \in A \cap B\text{?}\) Is \(9 \in A \cap B\text{?}\) Justify each answer.
      🔗
    2. Describe \(A \cap B\) in words. (Hint: what integers are both even and divisible by 3?)
      🔗
    3. Describe \(A \cap B \cap C\) in words.
      🔗
    4. Give an element of \(B \setminus A\text{.}\) Give an element of \(A \setminus B\text{.}\)
      🔗
    🔗
    Answer.
    (a) \(6 \in A \cap B\) (since 6 is even and divisible by 3); \(9 \notin A \cap B\) (since 9 is not even). (b) \(A \cap B\) is the set of multiples of 6. (c) \(A \cap B \cap C\) is the set of positive multiples of 6: \(\{6, 12, 18, \ldots\}\text{.}\) (d) \(3 \in B \setminus A\text{;}\) \(2 \in A \setminus B\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.2. \([\mathbf{F}]\) Membership and Subsets.

    For each of the following, decide whether the statement is true or false. If true, give a brief justification; if false, give a counterexample.
    1. \(\displaystyle \emptyset \subseteq \{1, 2, 3\}\)
      🔗
    2. \(\displaystyle \{1\} \in \{\{1\}, \{2\}, \{3\}\}\)
      🔗
    3. \(\displaystyle 1 \in \{\{1\}, \{2\}, \{3\}\}\)
      🔗
    4. If \(A \subseteq B\) and \(B \subseteq A\text{,}\) then \(A = B\text{.}\)
      🔗
    5. \(\displaystyle \{n \in \N : n^2 \lt 10\} = \{1, 2, 3\}\)
      🔗
    🔗
    Answer.
    (a) True: the empty set is a subset of every set. (b) True: \(\{1\}\) is one of the three elements of this set. (c) False: the elements of \(\{\{1\},\{2\},\{3\}\}\) are sets, not numbers; \(1\) is not one of them. (d) True: this is the Axiom of Extensionality. (e) True: \(1^2=1 \lt 10\text{,}\) \(2^2=4 \lt 10\text{,}\) \(3^2=9 \lt 10\text{,}\) \(4^2=16 \geq 10\text{,}\) so the set is exactly \(\{1,2,3\}\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.3. \([\mathbf{F}]\) Identifying Function Properties.

    For each function, determine (with a brief justification but without a formal proof) whether it is injective, surjective, bijective, or none of these. If it is bijective, describe the inverse function.
    1. \(f : \R \to \R\text{,}\) \(f(x) = x^3\)
      🔗
    2. \(g : \R \to [0,\infty)\text{,}\) \(g(x) = x^2\)
      🔗
    3. \(h : \N \to \N\text{,}\) \(h(n) = n + 1\)
      🔗
    4. \(k : \Z \to \Z\text{,}\) \(k(n) = n - 7\)
      🔗
    🔗
    Answer.
    (a) Bijective. Every real number has a unique real cube root; \(f^{-1}(y) = y^{1/3}\text{.}\) (b) Not injective (since \(g(-1)=g(1)=1\)), but surjective (every nonneg. real is the square of its square root). (c) Injective but not surjective: \(1 \in \N\) has no preimage (there is no \(n \in \N\) with \(n+1=1\text{,}\) since \(n=0 \notin \N\) by the convention \(\N = \{1,2,\ldots\}\)). (d) Bijective; \(k^{-1}(m) = m + 7\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.4. \([\mathbf{F}]\) Countable or Uncountable?

    For each set below, state (without proof) whether it is finite, countably infinite, or uncountable. Briefly explain your reasoning.
    1. The set of prime numbers.
      🔗
    2. The set of irrational numbers.
      🔗
    3. The set \(\{1/n : n \in \N\}\text{.}\)
      🔗
    4. The interval \((0,1)\text{.}\)
      🔗
    5. The set \(\Q \times \Q\text{.}\)
      🔗
    🔗
    Answer.
    (a) Countably infinite (a subset of \(\N\text{;}\) infinite by Euclid’s theorem). (b) Uncountable (if it were countable, then \(\R = \Q \cup (\R \setminus \Q)\) would be a countable union of countable sets, contradicting Theorem 1.21). (c) Countably infinite (in bijection with \(\N\) via \(n \mapsto 1/n\)). (d) Uncountable (bijection with \(\R\) via, e.g., \(x \mapsto \tan(\pi x - \pi/2)\text{;}\) or directly from Theorem 1.21). (e) Countably infinite (product of two countable sets by Prop. 1.18).
    🔗

    Standard Problems.

    🔗

    Checkpoint 4.5. \([\mathbf{S}]\) Element-Chasing: De Morgan’s Law.

    Let \(A\text{,}\) \(B\text{,}\) and \(C\) be subsets of a universal set \(U\text{,}\) with complements taken relative to \(U\text{.}\) Prove:
    \begin{equation*} C \setminus (A \cup B) = (C \setminus A) \cap (C \setminus B). \end{equation*}
    Your proof must use the element-chasing method: show each set is a subset of the other.
    🔗
    Hint.
    Recall that \(x \in C \setminus A\) means \(x \in C\) and \(x \notin A\text{.}\) Use the fact that \(x \notin A \cup B\) is equivalent to \(x \notin A\) and \(x \notin B\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.6. \([\mathbf{S}]\) Proving Injectivity and Non-surjectivity.

    Let \(f : \Z \to \Z\) be defined by \(f(n) = 3n - 1\text{.}\)
    1. Prove that \(f\) is injective.
      🔗
    2. Prove that \(f\) is not surjective.
      🔗
    3. Identify the range of \(f\) and describe it as a familiar subset of \(\Z\text{.}\)
      🔗
    🔗
    🔗

    Checkpoint 4.7. \([\mathbf{S}]\) Proving Bijectivity and Finding the Inverse.

    Define \(f : \N \to \N\) by
    \begin{equation*} f(n) = \begin{cases} n + 1 \amp \text{if } n \text{ is odd,} \\ n - 1 \amp \text{if } n \text{ is even.}\end{cases} \end{equation*}
    1. Verify \(f\) on the first six values: \(f(1), f(2), \ldots, f(6)\text{.}\)
      🔗
    2. Prove that \(f\) is injective.
      🔗
    3. Prove that \(f\) is surjective.
      🔗
    4. Find \(f^{-1}\text{.}\) (You may be surprised by the answer.)
      🔗
    🔗
    Hint.
    For part (b): if \(f(m) = f(n)\text{,}\) consider the cases where \(m\) and \(n\) are both odd, both even, or have different parity.
    🔗
    🔗
    🔗

    Checkpoint 4.8. \([\mathbf{S}]\) Even Integers Are Countably Infinite.

    Let \(E = \{2n : n \in \Z\}\) be the set of all even integers. Prove that \(E\) is countably infinite by constructing an explicit bijection \(g : \N \to E\text{.}\) Verify that your function is both injective and surjective.
    🔗
    Hint.
    Use the bijection \(\N \to \Z\) from Worked Example 4, then compose with \(n \mapsto 2n\text{.}\) Alternatively, define a direct bijection by interleaving positive and negative even integers.
    🔗

    Challenge Problems.

    🔗

    Checkpoint 4.9. \([\mathbf{C}]\) A Partial Converse for Composition.

    Let \(f : A \to B\) and \(g : B \to C\text{.}\)
    1. Prove: if \(g \circ f\) is injective, then \(f\) is injective.
      🔗
    2. Give a specific example showing that \(g\) need not be injective: find sets \(A\text{,}\) \(B\text{,}\) \(C\) and functions \(f\text{,}\) \(g\) such that \(g \circ f\) is injective but \(g\) is not.
      🔗
    3. State and prove the analogous partial converse for surjectivity: if \(g \circ f\) is surjective, which of \(f\) or \(g\) must be surjective?
      🔗
    🔗
    Hint.
    For (a): suppose \(f(a_1) = f(a_2)\) and apply \(g\) to both sides; use injectivity of \(g \circ f\text{.}\) For (c): the answer is \(g\text{;}\) to prove it, let \(c \in C\) and use surjectivity of \(g \circ f\) to find \(a \in A\) with \((g \circ f)(a) = c\text{,}\) then conclude about \(g\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.10. \([\mathbf{C}]\) Cantor’s Diagonal Argument — Guided Proof.

    In this problem you will write a complete proof that the interval \((0,1)\) is uncountable, following Cantor’s diagonal argument. Fill in each step with a complete mathematical justification.
    🔗
    1. State the assumption for contradiction: what are you assuming about \((0,1)\text{?}\)
      🔗
      🔗
    2. Under this assumption, how can you represent the elements of \((0,1)\text{?}\) (Describe the “list” and the grid of decimal digits.)
      🔗
      🔗
    3. Describe the construction of the diagonal number \(x\text{.}\) Be specific: for each position \(i\text{,}\) how do you choose the \(i\)th digit of \(x\text{?}\) Why do you avoid using 0 or 9? (Hint: think about \(0.999\ldots\text{.}\))
      🔗
      🔗
    4. Prove that \(x \in (0,1)\text{.}\)
      🔗
      🔗
    5. Prove that \(x\) is not equal to any element in the list. For a specific \(r_n\text{,}\) at which decimal digit does \(x\) differ from \(r_n\text{?}\) Why does this guarantee \(x \neq r_n\text{?}\)
      🔗
      🔗
    6. State the contradiction and conclude.
      🔗
      🔗
