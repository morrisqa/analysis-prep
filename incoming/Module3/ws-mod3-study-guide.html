    Section 2 Module 3: Companion Reading and Study Guide

    This study guide is organized into four reading blocks. For each block, read the assigned pages in Zorn and/or Hirst before answering the reading-check questions. The questions are designed to confirm comprehension and surface any notation differences between sources. Write your answers in your notebook; these are not submitted.
    🔗
    Reading-check questions are not graded. They are checkpoints: if you cannot answer a question after reading the section, re-read with that question in mind before moving on.
    🔗

    Part A: Sets.

    Read: Zorn §1.2 (pp. 10–18); Hirst §5.1–5.2.
    🔗
    Zorn §1.2 develops set notation and operations informally but rigorously, with examples drawn from analysis (intervals, number systems). Hirst §5.1–5.2 covers the same ground using the Axiom of Extensionality and the formal set-builder notation from predicate logic. After reading both, you should be able to move fluently between the two presentations.
    🔗
    Key definitions to identify as you read: membership (\(x \in A\)), subset (\(A \subseteq B\)), proper subset (\(A \subsetneq B\)), the empty set (\(\emptyset\)), union (\(A \cup B\)), intersection (\(A \cap B\)), set difference (\(A \setminus B\)), Cartesian product (\(A \times B\)), power set (\(\mathcal{P}(A)\)), and De Morgan’s laws.
    🔗
    🔗

    Checkpoint 2.1. Axiom of Extensionality.

    State the Axiom of Extensionality (Hirst Theorem 47) in your own words. Then explain why it implies the standard proof strategy for set equality: to show \(A = B\text{,}\) prove \(A \subseteq B\) and \(B \subseteq A\) separately.
    🔗
    Hint.
    The Axiom says two sets are equal if and only if they have exactly the same elements. What does \(A \subseteq B\) and \(B \subseteq A\) together guarantee about membership?
    🔗
    🔗
    🔗

    Checkpoint 2.2. De Morgan’s Laws.

    State both of De Morgan’s laws for sets (Zorn p. 12 or Hirst §5.2). Then, for the law \((A \cup B)^c = A^c \cap B^c\) (where \(X^c\) denotes the complement of \(X\) in some universal set), write out the first direction of the element-chasing proof: assume \(x \in (A \cup B)^c\) and show \(x \in A^c \cap B^c\text{.}\) What logical connective converts \(x \notin A \cup B\) into two separate statements?
    🔗
    🔗

    Checkpoint 2.3. Cartesian Product Size.

    If \(|A| = m\) and \(|B| = n\) (where \(|S|\) denotes the number of elements of a finite set \(S\)), how many elements does \(A \times B\) have? How many elements does \(\mathcal{P}(A)\) have? Verify your formulas with \(A = \{1, 2\}\) and \(B = \{a, b, c\}\text{.}\)
    🔗
    Answer.
    \(|A \times B| = mn\) and \(|\mathcal{P}(A)| = 2^m\text{.}\) For the given sets: \(|A \times B| = 6\) and \(|\mathcal{P}(A)| = 4\text{.}\)
    🔗

    Part B: Functions.

    Read: Zorn §1.3 (pp. 19–31); Hirst §5.3–5.4.
    🔗
    Zorn §1.3 defines functions as three-part packages (domain, codomain, rule) and develops injectivity, surjectivity, bijectivity, composition, and inverse functions. Hirst §5.3–5.4 provides the set-theoretic foundation: functions as sets of ordered pairs, and images and preimages as derived sets. Both presentations are important; Zorn gives you the working definitions and Hirst makes the underlying structure explicit.
    🔗
    Key definitions to identify: function as a three-part package, range vs. codomain, injective (one-to-one), surjective (onto), bijective, composition \(g \circ f\text{,}\) inverse function \(f^{-1}\text{,}\) image \(f(U)\text{,}\) preimage \(f^{-1}(V)\text{.}\)
    🔗
    🔗

    Checkpoint 2.4. Range versus Codomain.

    Let \(f : \Z \to \Z\) be defined by \(f(n) = 2n\text{.}\)
    1. What is the range of \(f\text{?}\)
      🔗
    2. Is \(f\) surjective? Explain using the definition.
      🔗
    3. How would you change the codomain to make \(f\) surjective (without changing the domain or the rule)?
      🔗
    🔗
    Answer.
    (a) The range is the set of even integers, \(\{2n : n \in \Z\}\text{.}\) (b) Not surjective: \(1 \in \Z\) is not in the range (there is no integer \(n\) with \(2n = 1\)). (c) Change the codomain to the even integers.
    🔗
    🔗
    🔗

    Checkpoint 2.5. Reading the Injectivity Definition.

    1. Write the contrapositive of this implication and explain why it gives an equivalent condition for injectivity.
      🔗
    2. Use the original implication to prove that \(f : \R \to \R\text{,}\) \(f(x) = 5x - 3\text{,}\) is injective. Write every step as a complete sentence.

    Checkpoint 2.6. Inverse Functions and Bijectivity.

    State the relationship between bijectivity and the existence of an inverse function (Zorn Definition 1.11 or Hirst §5.4). Then: for \(f : \R \to \R\text{,}\) \(f(x) = 3x - 5\text{,}\) find \(f^{-1}\) explicitly and verify that \(f(f^{-1}(y)) = y\) for all \(y \in \R\) and \(f^{-1}(f(x)) = x\) for all \(x \in \R\text{.}\)
    🔗
    Hint.
    To find \(f^{-1}\text{,}\) set \(y = 3x - 5\) and solve for \(x\) in terms of \(y\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 2.7. Preimage.

    Let \(f : \R \to \R\text{,}\) \(f(x) = x^2\text{.}\) Compute the following preimages:
    1. \(\displaystyle f^{-1}(\{4\})\)
      🔗
    2. \(\displaystyle f^{-1}([0, 9])\)
      🔗
    3. \(\displaystyle f^{-1}((-1, 0))\)
      🔗
    Notice that \(f^{-1}\) here denotes the preimage operator (a set-valued function), not an inverse function (which does not exist for this \(f\)). Why does the preimage of any set always exist, even when the inverse function does not?
    🔗
    Answer.
    (a) \(f^{-1}(\{4\}) = \{-2, 2\}\text{.}\) (b) \(f^{-1}([0,9]) = [-3, 3]\text{.}\) (c) \(f^{-1}((-1,0)) = \emptyset\) (since \(x^2 \geq 0\) for all \(x \in \R\)). The preimage is defined purely in terms of which elements of the domain map into the target set; it does not require the function to be injective or surjective.
    🔗
    🔗
    🔗

    Part C: Equivalence Relations.

    Read: Zorn §1.3, the final two pages on relations (following the discussion of inverse functions).
    🔗
    A relation on a set \(A\) is a subset \(R \subseteq A \times A\text{.}\) We write \(a \sim b\) (or \(aRb\)) when \((a, b) \in R\text{.}\) An equivalence relation is a relation that is reflexive, symmetric, and transitive. Equivalence relations partition a set into disjoint equivalence classes; this structure reappears in abstract algebra and topology. For our purposes in real analysis, the most important equivalence relation is the one defining cardinality in Part D: \(A \sim B\) iff there exists a bijection \(A \to B\text{.}\)
    🔗
    🔗

    Checkpoint 2.8. Checking Equivalence Relation Axioms.

    Define a relation on \(\Z\) by: \(a \sim b\) if \(a - b\) is even (i.e., divisible by 2).
    1. Is \(\sim\) reflexive? (Is \(a \sim a\) for all \(a \in \Z\text{?}\))
      🔗
    2. Is \(\sim\) symmetric? (If \(a \sim b\text{,}\) does it follow that \(b \sim a\text{?}\))
      🔗
    3. Is \(\sim\) transitive? (If \(a \sim b\) and \(b \sim c\text{,}\) does it follow that \(a \sim c\text{?}\))
      🔗
    4. Describe the equivalence classes of \(\sim\text{.}\)
      🔗
    🔗
    Answer.
    (a) Yes: \(a - a = 0\) is even. (b) Yes: if \(a - b\) is even, then \(b - a = -(a-b)\) is also even. (c) Yes: if \(a - b = 2k\) and \(b - c = 2m\text{,}\) then \(a - c = 2(k+m)\) is even. (d) There are two equivalence classes: the even integers and the odd integers.
    🔗
    🔗
    🔗

    Part D: Cardinality.

    Read: Zorn §1.6 (pp. 52–61); Hirst §5.5.
    🔗
    Zorn §1.6 defines cardinality via bijection and develops the main countability results: Propositions 1.17–1.19 (subsets of countable sets; countable products; countable unions), Corollary 1.20 (\(\Q\) is countable), and Theorem 1.21 (\(\R\) is uncountable). Read each proof carefully; the proofs of the propositions use bijection constructions that are themselves important techniques.
    🔗
    Hirst §5.5 covers related material including the Cantor–Bernstein theorem (\(A \preceq B\) and \(B \preceq A\) imply \(A \sim B\)). You are not required to prove Cantor–Bernstein, but reading its statement gives you important context for how cardinality comparisons work in MAT 5610.
    🔗
    🔗
