    Section 5 Module 3: Bridge Reading Guide

    Read: Bauldry §2.1 (Introduction to Real Analysis, pp. 37–52, approximately): “The Topology of \(\R\text{.}\)”
    🔗
    This reading is your first direct encounter with the material you will study in MAT 5610. Bauldry §2.1 develops the topology of the real line: neighborhoods, open and closed sets, interior and boundary points, and limit points (accumulation points). Every definition in this section is written in the set and function language of Module 3. The goal of this reading is not to master topology—that is MAT 5610’s job—but to see concretely how the vocabulary you have built is deployed in graduate-level analysis.
    🔗
    As you read, notice the following:
    • Neighborhoods are defined using absolute value (from Module 2) and described as open intervals, which are sets.
      🔗
      🔗
    • “Deleted neighborhoods” are formed using set difference (a Module 3 operation).
      🔗
      🔗
    • Open and closed sets are defined in terms of set-theoretic properties (every point is an interior point; the complement is open).
      🔗
      🔗
    • Accumulation points involve a quantified statement about neighborhoods, and the distinction between finite and infinite sets (cardinality) is used in the definition.
      🔗
      🔗
    🔗

    Checkpoint 5.1. Neighborhoods as Sets.

    Bauldry defines the \(\delta\)-neighborhood of a point \(c \in \R\) as the set \(N(c; \delta) = \{x \in \R : |x - c| \lt \delta\}\text{.}\)
    1. What interval (in standard notation) is \(N(c;\delta)\text{?}\)
      🔗
    2. Bauldry also defines the deleted \(\delta\)-neighborhood \(N^*(c;\delta) = N(c;\delta) \setminus \{c\}\text{.}\) Write this set using the Module 3 notation for set difference. Why is the point \(c\) removed?
      🔗
    3. Is \(N(c;\delta)\) an open set, a closed set, or neither? (Look up Bauldry’s definition of open set and apply it.)
      🔗
    🔗
    🔗

    Checkpoint 5.2. Set Operations in Topology.

    Bauldry defines the interior of a set \(S\) as the set of all interior points of \(S\text{,}\) where \(c\) is an interior point if some neighborhood of \(c\) is contained in \(S\) (i.e., \(\exists \delta \gt 0\) such that \(N(c;\delta) \subseteq S\)).
    1. Using Module 3 set notation, what does \(N(c;\delta) \subseteq S\) mean in terms of membership?
      🔗
    2. Bauldry states that an open set equals its own interior. What does this say about the relationship between a set and the subsets used to define it?
      🔗
    3. Find one set from Zorn Chapter 1 that is open and one that is closed (in the Bauldry sense). Verify your choices by checking the definition.
      🔗
    🔗
    🔗

    Checkpoint 5.3. Accumulation Points and Cardinality.

    A point \(c\) is an accumulation point (or limit point) of a set \(S\) if every deleted neighborhood of \(c\) contains at least one point of \(S\text{:}\)
    \begin{equation*} \forall \delta \gt 0,\quad N^*(c;\delta) \cap S \neq \emptyset. \end{equation*}
    1. Write this definition out using the set-builder and quantifier notation from Modules 1 and 3.
      🔗
    2. Is 0 an accumulation point of the set \(\{1/n : n \in \N\}\text{?}\) Explain by checking the definition: for any \(\delta \gt 0\text{,}\) can you find \(n \in \N\) such that \(1/n \in N^*(0;\delta)\text{?}\)
      🔗
    3. The set \(\{1/n : n \in \N\}\) is countably infinite (it is in bijection with \(\N\)). Its set of accumulation points, however, contains only one point. What is that point? Why does the size (cardinality) of the set not determine how many accumulation points it has?
      🔗

    Looking Ahead.

    The topology developed in Bauldry §2.1 is the setting for the definitions of limit and continuity in Bauldry §2.2. When Bauldry writes “\(f\) is continuous at \(c\)”, the definition quantifies over neighborhoods: for every \(\varepsilon\)-neighborhood of \(f(c)\text{,}\) there is a \(\delta\)-neighborhood of \(c\) that maps into it. This is a statement about preimages of sets under a function—exactly the preimage language from Hirst §5.4 that you read in the Study Guide.
    🔗
    You will return to these ideas in Module 6 (Limits, Continuity, and Uniform Continuity). For now, the goal is recognition: the set-theoretic vocabulary you built in Module 3 is not abstract machinery; it is the language of the definitions you will be working with throughout MAT 5610.
