    Section 2 Module 8: Companion Reading and Study Guide

    This guide accompanies four sections of Zorn’s Understanding Real Analysis. Section 5.1 introduces partitions and Darboux sums. Section 5.2 develops the integrability criterion. Section 5.3 identifies the main classes of integrable functions (continuous and monotone). Section 5.4 proves the Fundamental Theorem of Calculus.
    🔗
    Read each section before working its questions. The recurring theme is the integrability criterion: a function is Riemann integrable if and only if for every \(\varepsilon \gt 0\) there is a partition \(P\) with \(U(f,P) - L(f,P) \lt \varepsilon\text{.}\) Every positive result in this module is proved by exhibiting such a partition.
    🔗

    Section 5.1: Partitions and Darboux Sums.

    Read Zorn’s definitions of partition, Darboux sums, and upper and lower integrals carefully. The key notational distinction: \(M_i = \sup\{f(x) : x \in [x_{i-1}, x_i]\}\) is the supremum (not a sample value), and \(m_i = \inf\{f(x) : x \in [x_{i-1}, x_i]\}\) is the infimum. These always exist when \(f\) is bounded.
    🔗
    🔗

    Checkpoint 2.1. Partitions and Mesh.

    Define a partition \(P\) of \([a,b]\) and the mesh \(\|P\|\text{.}\) For \(P = \{0, 1/3, 2/3, 1\}\) of \([0,1]\text{,}\) compute \(\|P\|\text{.}\)
    🔗
    Answer.
    A partition of \([a,b]\) is a finite set \(P = \{x_0, x_1, \ldots, x_n\}\) with \(a = x_0 \lt x_1 \lt \cdots \lt x_n = b\text{.}\) The mesh is \(\|P\| = \max_{1 \le i \le n} \Delta x_i\) where \(\Delta x_i = x_i - x_{i-1}\text{.}\) For \(P = \{0, 1/3, 2/3, 1\}\text{,}\) each subinterval has length \(1/3\text{,}\) so \(\|P\| = 1/3\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 2.2. Upper Sums for \(f(x) = x^2\).

    For \(f(x) = x^2\) on \([0,1]\) with uniform partition \(P_n\) of \(n\) equal subintervals:
    1. What is \(\Delta x = 1/n\) and what are the partition points \(x_k = k/n\text{?}\)
      🔗
    2. Compute \(M_k = \sup f\) on \([x_{k-1}, x_k]\text{.}\) Since \(f\) is increasing, \(M_k = x_k^2 = k^2/n^2\text{.}\)
      🔗
    3. Write \(U(f, P_n) = \sum_{k=1}^{n} (k^2/n^2)(1/n)\) and use the formula \(\sum_{k=1}^{n} k^2 = n(n+1)(2n+1)/6\) to obtain \(U(f, P_n) = (n+1)(2n+1)/(6n^2)\text{.}\)
      🔗
    🔗
    Answer.
    (a) \(\Delta x = 1/n\text{;}\) \(x_k = k/n\) for \(k = 0, 1, \ldots, n\text{.}\) (b) Since \(x^2\) is increasing on \([0,1]\text{,}\) the supremum on \([(k-1)/n, k/n]\) is attained at the right endpoint: \(M_k = (k/n)^2 = k^2/n^2\text{.}\) (c)
    \begin{equation*} U(f, P_n) = \sum_{k=1}^{n} \frac{k^2}{n^2} \cdot \frac{1}{n} = \frac{1}{n^3} \sum_{k=1}^{n} k^2 = \frac{1}{n^3} \cdot \frac{n(n+1)(2n+1)}{6} = \frac{(n+1)(2n+1)}{6n^2}. \end{equation*}

    Section 5.2: The Integrability Criterion.

    The integrability criterion is the workhorse of this module. Read Zorn’s statement and proof carefully. Every positive integrability result — continuous functions, monotone functions — is proved by exhibiting a partition that makes \(U(f,P) - L(f,P)\) small.
    🔗
    🔗

    Checkpoint 2.3. Stating the Integrability Criterion.

    State the Riemann integrability criterion precisely. Why is \(U(f,P) - L(f,P)\) sometimes called the “oscillation sum”?
    🔗
    Answer.
    A bounded function \(f\) on \([a,b]\) is Riemann integrable if and only if for every \(\varepsilon \gt 0\) there exists a partition \(P\) of \([a,b]\) such that \(U(f,P) - L(f,P) \lt \varepsilon\text{.}\) The quantity \(U(f,P) - L(f,P) = \sum (M_i - m_i)\Delta x_i\) is the oscillation sum because \(M_i - m_i\) measures the oscillation of \(f\) on the \(i\)th subinterval — the spread between the largest and smallest values of \(f\) on that piece. When the total oscillation (weighted by subinterval length) can be made arbitrarily small, the function is integrable.
    🔗
    🔗
    🔗

    Checkpoint 2.4. The Dirichlet Function.

    For the Dirichlet function \(f(x) = 1\) if \(x \in \Q\text{,}\) \(f(x) = 0\) if \(x \notin \Q\text{:}\)
    1. What is \(M_k = \sup f\) on any subinterval \([x_{k-1}, x_k]\text{?}\) (Recall that the rationals are dense in \(\R\text{.}\))
      🔗
    2. What is \(m_k = \inf f\) on any subinterval? (Recall that the irrationals are also dense in \(\R\text{.}\))
      🔗
    3. Compute \(U(f,P) - L(f,P)\) for any partition \(P\) of \([0,1]\text{.}\)
      🔗
    4. Is the Dirichlet function Riemann integrable on \([0,1]\text{?}\)
      🔗
    🔗
    Answer.
    (a) Since \(\Q\) is dense in \(\R\text{,}\) every subinterval contains rationals, so \(M_k = 1\text{.}\) (b) Since \(\R \setminus \Q\) is dense in \(\R\text{,}\) every subinterval contains irrationals, so \(m_k = 0\text{.}\) (c) \(U(f,P) - L(f,P) = \sum (1 - 0)\Delta x_k = 1\) for any partition of \([0,1]\text{.}\) (d) No: since \(U(f,P) - L(f,P) = 1\) for every partition, the integrability criterion fails (take \(\varepsilon = 1/2\text{,}\) for instance). The upper integral equals 1 and the lower integral equals 0, so they are not equal and \(f\) is not Riemann integrable.
    🔗
    🔗
    🔗

    Section 5.3: Classes of Integrable Functions.

    Zorn establishes two main classes: continuous functions (using uniform continuity) and monotone functions (using a telescoping argument). Read both proofs, paying attention to where each uses special properties of the function class.
    🔗
    🔗

    Checkpoint 2.5. Continuous Implies Integrable.

    Sketch the proof that if \(f\) is continuous on \([a,b]\text{,}\) then \(f\) is Riemann integrable on \([a,b]\text{.}\) Which fact from Module 6 is used and where?
    🔗
    Answer.
    The key tool is the Heine-Cantor theorem (Module 6): a continuous function on a closed bounded interval is uniformly continuous. Given \(\varepsilon \gt 0\text{,}\) apply uniform continuity to get \(\delta \gt 0\) such that \(|x - y| \lt \delta \Rightarrow |f(x) - f(y)| \lt \varepsilon/(b-a)\text{.}\) Choose any partition \(P\) with mesh \(\|P\| \lt \delta\text{.}\) On each subinterval \([x_{i-1}, x_i]\text{,}\) any two points are within \(\delta\) of each other, so \(M_i - m_i \leq \varepsilon/(b-a)\) by uniform continuity. Then
    \begin{equation*} U(f,P) - L(f,P) = \sum_{i=1}^{n} (M_i - m_i)\Delta x_i \leq \frac{\varepsilon}{b-a} \sum_{i=1}^{n} \Delta x_i = \varepsilon. \end{equation*}
    By the integrability criterion, \(f\) is integrable. Uniform continuity is used to control \(M_i - m_i\text{;}\) pointwise continuity would not suffice because the same \(\delta\) must work everywhere on \([a,b]\) simultaneously.
    🔗
    🔗
    🔗

    Checkpoint 2.6. Monotone Implies Integrable.

    Prove that a monotone function on \([a,b]\) is Riemann integrable.
    1. Assume without loss of generality that \(f\) is increasing on \([a,b]\text{.}\) For the uniform partition \(P_n\) with \(n\) equal subintervals of width \((b-a)/n\text{,}\) show that
      \begin{equation*} U(f,P_n) - L(f,P_n) = \frac{1}{n}\sum_{k=1}^{n}[f(x_k) - f(x_{k-1})] = \frac{f(b) - f(a)}{n}, \end{equation*}
      using the telescoping nature of the sum and the fact that \(M_k = f(x_k)\) and \(m_k = f(x_{k-1})\) for an increasing function.
      🔗
    2. Apply the integrability criterion: given \(\varepsilon \gt 0\text{,}\) choose \(n \gt (f(b) - f(a))/\varepsilon\) to conclude.
      🔗
    🔗
    Answer.
    (a) For increasing \(f\text{,}\) on the \(k\)th subinterval \([x_{k-1}, x_k]\) the supremum is attained at the right endpoint and the infimum at the left: \(M_k = f(x_k)\) and \(m_k = f(x_{k-1})\text{.}\) With uniform partition width \(\Delta x = (b-a)/n\text{:}\)
    \begin{equation*} U(f,P_n) - L(f,P_n) = \frac{b-a}{n} \sum_{k=1}^{n} [f(x_k) - f(x_{k-1})] = \frac{b-a}{n} [f(b) - f(a)], \end{equation*}
    since the sum telescopes. (b) Given \(\varepsilon \gt 0\text{,}\) choose \(n \gt (b-a)(f(b)-f(a))/\varepsilon\) (or \(n = 1\) if \(f(b) = f(a)\)). Then \(U(f,P_n) - L(f,P_n) = (b-a)(f(b)-f(a))/n \lt \varepsilon\text{.}\) By the integrability criterion, \(f\) is integrable.
    🔗

    Section 5.4: The Fundamental Theorem of Calculus.

    Read both parts of the FTC carefully. Part 1 requires differentiating a function defined by an integral; Part 2 uses Part 1 together with the Module 7 corollary that a function with zero derivative on an interval is constant.
    🔗
    🔗

    Checkpoint 2.7. FTC Part 1 — Hypotheses and Statement.

    State FTC Part 1 precisely, including all hypotheses. What does it mean to say that \(F(x) = \int_a^x f(t)\,dt\) is differentiable at \(x\text{?}\) (You must compute \(F'(x)\) from the limit definition of the derivative.)
    🔗
    Answer.
    FTC Part 1. Let \(f\) be continuous on \([a,b]\) and define \(F(x) = \int_a^x f(t)\,dt\) for \(x \in [a,b]\text{.}\) Then \(F\) is differentiable on \((a,b)\) and \(F'(x) = f(x)\) for all \(x \in (a,b)\text{.}\) To say \(F\) is differentiable at \(x\) means that the limit
    \begin{equation*} F'(x) = \lim_{h \to 0} \frac{F(x+h) - F(x)}{h} = \lim_{h \to 0} \frac{1}{h}\int_x^{x+h} f(t)\,dt \end{equation*}
    exists and equals \(f(x)\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 2.8. FTC Part 2 — Statement and Proof.

    1. State FTC Part 2 precisely, listing all hypotheses.
      🔗
    2. Prove FTC Part 2 using FTC Part 1 as a lemma: if \(F' = f\) on \([a,b]\text{,}\) define \(G(x) = \int_a^x f\text{.}\) By Part 1, \(G' = f = F'\text{,}\) so \((G - F)' = 0\text{.}\) By the Module 7 corollary (a function with zero derivative on an interval is constant), \(G - F = C\) for some constant. Evaluate at \(x = a\) to find \(C\text{,}\) then at \(x = b\) to conclude.
      🔗
    🔗
    Answer.
    (a) FTC Part 2. Let \(f\) be continuous on \([a,b]\) and let \(F\) be differentiable on \([a,b]\) with \(F' = f\text{.}\) Then
    \begin{equation*} \int_a^b f(x)\,dx = F(b) - F(a). \end{equation*}
    (b) Define \(G(x) = \int_a^x f(t)\,dt\text{.}\) By FTC Part 1, \(G'(x) = f(x) = F'(x)\) for all \(x \in (a,b)\text{.}\) Hence \((G - F)'(x) = 0\) on \((a,b)\text{.}\) By the Module 7 MVT corollary, \(G(x) - F(x) = C\) for some constant \(C \in \R\text{.}\) Evaluating at \(x = a\text{:}\) \(G(a) - F(a) = 0 - F(a) = -F(a)\text{,}\) so \(C = -F(a)\text{.}\) Thus \(G(x) = F(x) - F(a)\) for all \(x \in [a,b]\text{.}\) Evaluating at \(x = b\text{:}\) \(\int_a^b f = G(b) = F(b) - F(a)\text{.}\)
