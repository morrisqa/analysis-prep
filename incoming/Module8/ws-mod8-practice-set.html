    Section 4 Module 8: Practice Problem Set

    Problems are labeled \([\mathbf{F}]\) (Foundational), \([\mathbf{S}]\) (Standard), and \([\mathbf{C}]\) (Challenge). Work in order within each level.
    🔗
    These problems are not submitted, but you should write out complete solutions. For any problem that asks you to prove something, apply the standards from the Worked Examples: strategy stated up front, complete sentences, every step justified, and every theorem invoked by name.
    🔗

    Foundational Problems.

    🔗

    Checkpoint 4.1. \([\mathbf{F}]\) Darboux Sums by Hand.

    For \(f(x) = x^2\) on \([0,1]\) with partition \(P = \{0, 1/2, 1\}\text{:}\)
    1. Compute \(M_1 = \sup f\) on \([0, 1/2]\) and \(M_2 = \sup f\) on \([1/2, 1]\text{.}\)
      🔗
    2. Compute \(m_1 = \inf f\) on \([0, 1/2]\) and \(m_2 = \inf f\) on \([1/2, 1]\text{.}\)
      🔗
    3. Compute \(U(f,P)\) and \(L(f,P)\text{.}\)
      🔗
    4. Compute \(U(f,P) - L(f,P)\text{.}\)
      🔗
    🔗
    Answer.
    Since \(f(x) = x^2\) is increasing on \([0,1]\text{,}\) the supremum on each subinterval is at the right endpoint and the infimum at the left. (a) \(M_1 = (1/2)^2 = 1/4\text{;}\) \(M_2 = 1^2 = 1\text{.}\) (b) \(m_1 = 0^2 = 0\text{;}\) \(m_2 = (1/2)^2 = 1/4\text{.}\) (c) Each subinterval has width \(1/2\text{,}\) so \(U(f,P) = (1/4)(1/2) + (1)(1/2) = 1/8 + 1/2 = 5/8\) and \(L(f,P) = (0)(1/2) + (1/4)(1/2) = 0 + 1/8 = 1/8\text{.}\) (d) \(U(f,P) - L(f,P) = 5/8 - 1/8 = 1/2\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.2. \([\mathbf{F}]\) FTC Evaluations.

    Use FTC Part 2 to evaluate each integral. For each one, state the antiderivative \(F\text{,}\) verify \(F' = f\text{,}\) and compute \(F(b) - F(a)\text{.}\)
    1. \(\displaystyle \displaystyle\int_0^1 x^3\,dx\)
      🔗
    2. \(\displaystyle \displaystyle\int_0^{\pi/2} \cos(x)\,dx\)
      🔗
    3. \(\displaystyle \displaystyle\int_1^e \frac{1}{x}\,dx\)
      🔗
    4. \(\displaystyle \displaystyle\int_0^1 e^x\,dx\)
      🔗
    🔗
    Answer.
    (a) \(F(x) = x^4/4\text{;}\) \(F'(x) = x^3\text{;}\) \(F(1) - F(0) = 1/4 - 0 = 1/4\text{.}\) (b) \(F(x) = \sin(x)\text{;}\) \(F'(x) = \cos(x)\text{;}\) \(F(\pi/2) - F(0) = 1 - 0 = 1\text{.}\) (c) \(F(x) = \ln(x)\text{;}\) \(F'(x) = 1/x\text{;}\) \(F(e) - F(1) = 1 - 0 = 1\text{.}\) (d) \(F(x) = e^x\text{;}\) \(F'(x) = e^x\text{;}\) \(F(1) - F(0) = e - 1\text{.}\)
    🔗

    Checkpoint 4.3. \([\mathbf{F}]\) FTC Part 1 Application.

    Use FTC Part 1 to compute \(\dfrac{d}{dx}\int_0^x (t^2 + \sin t)\,dt\text{.}\) Then use FTC Part 1 and the chain rule to compute \(\dfrac{d}{dx}\int_0^{x^2} e^t\,dt\text{.}\)
    🔗
    Answer.
    By FTC Part 1 (since \(t^2 + \sin t\) is continuous), \(\dfrac{d}{dx}\int_0^x (t^2 + \sin t)\,dt = x^2 + \sin x\text{.}\) For the second integral, write \(G(u) = \int_0^u e^t\,dt\text{,}\) so the integral equals \(G(x^2)\text{.}\) By FTC Part 1, \(G'(u) = e^u\text{.}\) By the chain rule:
    \begin{equation*} \frac{d}{dx} G(x^2) = G'(x^2) \cdot 2x = e^{x^2} \cdot 2x. \end{equation*}
    🔗
    🔗

    Checkpoint 4.4. \([\mathbf{F}]\) Linearity.

    Given \(\int_0^1 f = 3\) and \(\int_0^1 g = -1\text{,}\) compute:
    1. \(\displaystyle \displaystyle\int_0^1 (2f + 3g)\)
      🔗
    2. \(\displaystyle \displaystyle\int_0^1 (f - g)\)
      🔗
    3. \(\displaystyle \displaystyle\int_0^1 5f\)
      🔗
    🔗
    Answer.
    (a) By linearity: \(2(3) + 3(-1) = 6 - 3 = 3\text{.}\) (b) \(3 - (-1) = 4\text{.}\) (c) \(5(3) = 15\text{.}\)

    Checkpoint 4.5. \([\mathbf{S}]\) Integrability of \(f(x) = x^2\).

    Prove that \(f(x) = x^2\) is Riemann integrable on \([0,1]\) using the integrability criterion. Use the uniform partition \(P_n\) and show that \(U(f,P_n) - L(f,P_n) \to 0\) as \(n \to \infty\text{.}\)
    🔗
    Your proof should: (i) compute \(U(f,P_n)\) and \(L(f,P_n)\) using the formula \(\sum_{k=1}^n k^2 = n(n+1)(2n+1)/6\text{;}\) (ii) compute the difference; (iii) invoke the integrability criterion.
    🔗
    Hint.
    For \(P_n\) with \(x_k = k/n\text{:}\) since \(f\) is increasing, \(M_k = k^2/n^2\) and \(m_k = (k-1)^2/n^2\text{.}\) Then
    \begin{align*} U(f,P_n) \amp= \frac{1}{n^3}\sum_{k=1}^n k^2 = \frac{(n+1)(2n+1)}{6n^2},\\ L(f,P_n) \amp= \frac{1}{n^3}\sum_{k=1}^n (k-1)^2 = \frac{(n-1)(2n-1)}{6n^2}. \end{align*}
    Compute the difference and take \(n \to \infty\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.6. \([\mathbf{S}]\) Integration by Parts.

    Prove integration by parts from FTC: if \(u\) and \(v\) are differentiable on \([a,b]\) with \(u'\) and \(v'\) continuous, then
    \begin{equation*} \int_a^b u(x)\,v'(x)\,dx = \bigl[u(x)v(x)\bigr]_a^b - \int_a^b u'(x)\,v(x)\,dx. \end{equation*}
    🔗
    Your proof must start from the product rule for derivatives and apply FTC Part 2 to \((uv)'\text{.}\)
    🔗
    Answer.
    By the product rule, \((uv)' = u'v + uv'\text{.}\) Since \(u', v'\) are continuous and \(u, v\) are differentiable, \((uv)'\) is continuous on \([a,b]\text{.}\) Integrating both sides using FTC Part 2 (with antiderivative \(uv\) for \((uv)'\)):
    \begin{equation*} \int_a^b (uv)'\,dx = [u(x)v(x)]_a^b. \end{equation*}
    By linearity of the integral:
    \begin{equation*} \int_a^b u'v\,dx + \int_a^b uv'\,dx = [uv]_a^b. \end{equation*}
    Rearranging:
    \begin{equation*} \int_a^b u\,v'\,dx = [uv]_a^b - \int_a^b u'\,v\,dx. \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 4.7. \([\mathbf{S}]\) Bounding Integrals.

    Prove: if \(f\) is Riemann integrable on \([a,b]\) and \(m \leq f(x) \leq M\) for all \(x \in [a,b]\text{,}\) then
    \begin{equation*} m(b-a) \leq \int_a^b f(x)\,dx \leq M(b-a). \end{equation*}
    🔗
    Use the monotonicity of the Riemann integral (if \(f \leq g\) on \([a,b]\) then \(\int f \leq \int g\)) and the computation \(\int_a^b M\,dx = M(b-a)\) for a constant.
    🔗
    Answer.
    Since \(m \leq f(x) \leq M\) for all \(x \in [a,b]\text{,}\) monotonicity of the integral gives
    \begin{equation*} \int_a^b m\,dx \leq \int_a^b f(x)\,dx \leq \int_a^b M\,dx. \end{equation*}
    Since \(m\) and \(M\) are constants, their integrals are \(m(b-a)\) and \(M(b-a)\) respectively (by the assessment, constant functions are integrable with \(\int_a^b c\,dx = c(b-a)\)). Hence \(m(b-a) \leq \int_a^b f \leq M(b-a)\text{.}\)
    🔗
    🔗
    🔗

    Checkpoint 4.8. \([\mathbf{S}]\) Monotone Implies Integrable.

    Prove: if \(f\) is increasing on \([a,b]\text{,}\) then \(f\) is Riemann integrable on \([a,b]\text{.}\) Follow the strategy of Study Guide Exercise sg-53-2.
    🔗
    Hint.
    For the uniform partition \(P_n\) with subinterval width \((b-a)/n\text{,}\) note that \(M_k = f(x_k)\) and \(m_k = f(x_{k-1})\) (since \(f\) is increasing). Then
    \begin{equation*} U(f,P_n) - L(f,P_n) = \frac{b-a}{n}\sum_{k=1}^n[f(x_k) - f(x_{k-1})] = \frac{(b-a)[f(b) - f(a)]}{n} \to 0. \end{equation*}
    🔗
    🔗
    🔗

    Checkpoint 4.9. \([\mathbf{S}]\) An Integral Inequality.

    Prove: if \(f\) is Riemann integrable on \([a,b]\text{,}\) then \(|f|\) is also Riemann integrable on \([a,b]\) and
    \begin{equation*} \left|\int_a^b f(x)\,dx\right| \leq \int_a^b |f(x)|\,dx. \end{equation*}
    🔗
    For the inequality, use \(-|f(x)| \leq f(x) \leq |f(x)|\) and apply monotonicity of the integral twice.
    🔗
    Hint.
    From \(-|f(x)| \leq f(x) \leq |f(x)|\text{,}\) monotonicity gives \(-\int|f| \leq \int f \leq \int|f|\text{,}\) which is equivalent to \(|\int f| \leq \int|f|\text{.}\) (The integrability of \(|f|\) follows from the integrability criterion applied to \(|f|\text{,}\) using the fact that the oscillation of \(|f|\) on any interval is bounded by the oscillation of \(f\text{:}\) \(|\,|f(x)| - |f(y)|\,| \leq |f(x) - f(y)|\) by the reverse triangle inequality.)
    🔗

    Checkpoint 4.10. \([\mathbf{C}]\) FTC Part 2 from First Principles.

    Prove FTC Part 2 in full, using FTC Part 1 as a lemma and the Module 7 corollary that a function with zero derivative on an open interval is constant on that interval.
    🔗
    Your proof must have the following steps: (i) define \(G(x) = \int_a^x f\) and invoke FTC Part 1 to conclude \(G' = f = F'\text{;}\) (ii) apply the Module 7 corollary to \(G - F\text{;}\) (iii) evaluate at \(x = a\) to determine the constant; (iv) evaluate at \(x = b\) to conclude.
    🔗
    Hint.
    At step (iii): \(G(a) = \int_a^a f = 0\) and \((G - F)(a) = G(a) - F(a) = -F(a)\text{.}\) So the constant is \(C = -F(a)\text{,}\) giving \(G(x) = F(x) - F(a)\text{.}\) At step (iv): \(\int_a^b f = G(b) = F(b) - F(a)\text{.}\)
    🔗

    Checkpoint 4.11. \([\mathbf{C}]\) A Non-Integrable Function.

    Prove that the Dirichlet function
    \begin{equation*} f(x) = \begin{cases} 1 \amp x \in \Q \\ 0 \amp x \notin \Q \end{cases} \end{equation*}
    is not Riemann integrable on \([0,1]\text{.}\)
    🔗
    Your proof must: (i) show that \(M_k = 1\) and \(m_k = 0\) for every subinterval of every partition, citing density of \(\Q\) and \(\R \setminus \Q\) in \(\R\text{;}\) (ii) conclude that \(U(f,P) = 1\) and \(L(f,P) = 0\) for every partition \(P\text{;}\) (iii) state that the upper integral equals 1 and the lower integral equals 0, so they are unequal and \(f\) is not integrable.
